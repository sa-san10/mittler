# Mittler スターターガイド（人間用）

> 初めての方は、短い入口の [スターターガイド](スターターガイド.md) からご覧ください。このページでは、画面の構成と操作を詳しく説明します。

Mittler は、VS Code の中で動く動画エディタです。タイムラインで動画・画像・字幕・セリフ（TTS）・効果音・音楽・エフェクトを並べ、止めた場所の 1 コマを本番と同じ絵で確かめて MP4 に書き出します。

右側に Claude Code を開いておけば、エフェクトを書いてもらったりタイムラインを直してもらったりすることもできます（Claude が直した内容はすぐ画面に反映されます）。

ボタンやトラック名の頭には 1 色の線のアイコンが付きます（下の図では名前だけで示しています）。

## 1. はじめる前に（PC ごとに1回）

短い手順は [スターターガイド](スターターガイド.md) の 1・2 を参照してください（`python setup\mittler_setup.py` で必要なものがそろっているか確認できます）。

1. **Mittler を置く**：`git clone https://github.com/sa-san10/mittler.git`（置き場所はどこでも構いません）。
2. **VS Code に入れる**：`python tools\install_vscode.py`（実行する python はどれでも構いません）。
3. **どの PC で絵を描くかを決める**：**VS Code（Mittler）が動いている PC で描きます**。
   - 描く python（numpy・opencv・Pillow が入っている環境）を、VS Code の設定（`settings.json`）に指定します。
     ```json
     "mittler.render.python": "C:\\path\\to\\venv\\Scripts\\python.exe",
     "mittler.render.ffmpegDir": "C:\\path\\to\\ffmpeg\\bin"
     ```
     - ffmpeg が PATH に通っていれば `ffmpegDir` は不要です。
     - 設定を変えたら「ウィンドウの再読み込み」を行います（すでに開いている編集画面は、開いた時点の設定のまま動きます）。
   - 設定が無い場合は自動で探します（探索順：タイムラインの `render.python`（無ければ既定の場所）→ PATH の python）。PATH の python にパッケージが入っていれば設定なしで描けます。その他の設定（解析の python・VOICEVOX など）の一覧は `docs/インストールガイド.md` の 12 にあります。
   - 描く python が無い PC から別の PC（GPU のある PC など）の作品を使う場合は、VS Code の **Remote-SSH** でその PC に接続して開きます（`docs/インストールガイド.md` の「10. リモートで使うには Remote-SSH」）。
4. **Mittler を新しくしたとき（`git pull` したとき）**：VS Code で「ウィンドウの再読み込み」を実行します。`package.json`・`package.nls*.json` が変わったときだけ 2 をもう一度実行します。
5. **画面の言葉**：**はじめは英語**です（このガイドは日本語の画面の言葉で書いています）。
   - 日本語にするには、編集画面の上のバーの右端にある **EN／日本語** で「日本語」を押します。開いている窓・右の欄・ツールチップもその場で切りかわり、VS Code 内では設定 `"mittler.language": "ja"` に保存されて次回からも日本語になります。
   - 先に `settings.json` へ `"mittler.language": "ja"` と書いておいても構いません。言語設定は PC ごとで、作品ファイルには書きません。
   - ブラウザで直接開いた場合はそのブラウザが記憶します（URL に `&lang=ja` を付けるとそれが優先されます）。
   - コマンドパレットのコマンド名・設定の説明は、VS Code の表示言語に合わせられます（日本語の VS Code なら日本語）。

## 2. 新しい作品を作る

次のどの方法でも同じ構成の作品が作られます。フォルダ名は**英数字と `-` `_` のみ**とし、中身のあるフォルダには作らないでください。

- **「＋ 新規」ボタン**（すでに作品を開いているとき）：上のバーの作品名の右にある **＋ 新規** を押し、窓「新しい作品を作る（新規プロジェクト）」で置く場所（初期値は今の作品の親フォルダ。VS Code 内では「選ぶ…」で選択可能）・フォルダの名前・表示名（日本語可）・大きさ（初期値は今の作品と同じ）・fps・長さを入力して **作る** を押します。新しいタブでタイムラインが開き、元の作品はそのまま残ります。
- **VS Code のコマンド**（まだ作品を開いていないとき）：コマンドパレット（Ctrl+Shift+P）→ **「Mittler: 新しい作品を作る」**（「ファイル → 新しいファイル…」にも同じ項目があります）を選び、置く場所（親フォルダ）→ 作品フォルダの名前 → 表示名を入力すると作成され、タイムラインが開きます。
- **エージェントに頼む**：空のフォルダを VS Code で開き、右の Claude Code に「Mittler で新しいプロジェクトを始めたい」と伝えます（「縦のショートで」「名前は○○」なども添えられます）。空の作品を作成し、開き方と次の手順を案内します（Claude Code のスキル `mittler-new-project`。導入方法は下の「スキルの入れ方」）。
- **コマンドで作る**：`tools\mittler.cmd node tools\new_project.js <作品フォルダ> --title "わたしのアニメ" --duration 90`（Node が入っていれば `node tools\new_project.js …` でも実行可）。幅・高さは偶数、fps・長さは正の数でないと作らずに理由を表示します。

最初のトラック・メタデータの段の名前（字幕・映像・動画化予定・効果音 1・音楽・カット・ト書き）は、作成時の言語になります。「＋ 新規」は画面の言葉、「Mittler: 新しい作品を作る」は設定 `mittler.language`、コマンドラインは `--lang ja`（省略時は英語：Subtitles・Video…）が適用されます。名前はあとから自由に変更できます。

作成されるフォルダ構成（見本は `templates/project/`）：

```
my-anime-01/
  my-anime-01.cut.json   タイムライン（正本。編集画面で直すと自動で保存）
  characters.json        登場キャラの設定
  effects/               エフェクトのコード（字幕・重ね絵・フェード・色の手直し）
  assets/                素材（git に入れない）
    images/ videos/ sfx/ bgm/ music/ voice/ fonts/ characters/ overlays/
  work/proxy/            再生用の動画（WebM）
  output/                書き出した MP4
  CLAUDE.md  README.md  .gitignore   （git も最初のコミットまで済み）
```

### 素材の入れ方

素材はエクスプローラーで `assets/` の下に入れます。左のアセット窓に自動で表示されます（出なければ ↻ を押します）。

- 音楽は `assets/bgm/`、セリフの音声は `assets/voice/` に入れると、それぞれ「音楽」「TTS済み」タブに表示されます。それ以外の音は「音声」タブに出ます。
- 字幕フォントは `assets/fonts/NotoSerifJP-Regular.ttf` を優先し、無ければ Windows の游ゴシックで描画します。

### スキルの入れ方（PC ごとに1回。Mittler を新しくしたら、もう一度）

- `python setup\mittler_setup.py --install-skill` を実行します（このリポジトリの `skills/mittler-new-project/` を `%USERPROFILE%\.claude\skills\` にコピーし、隣に Mittler の場所を書き出します）。
- スキルは Mittler の場所（環境変数 `MITTLER_DIR` → スキルの隣の `mittler_dir.txt` → 入っている拡張の入口）を探して手順書を読むだけなので、手順を修正しても入れ直す必要はありません。
- 新しい PC への導入や PC の移行については、[インストールガイド.md](インストールガイド.md)（Python・ffmpeg・拡張・エージェントの設定・鍵・キャラのプリセット・作品の戻し方）を参照してください。

## 3. 画面

| 場所 | できること |
|---|---|
| 上のバー | 左から：アセット（アセット窓の開閉）、作品名、**＋ 新規**（新しい作品を作る）、動画の長さ（時計のアイコン）、動画の大きさ、PNG で保存、読み直す、取り消し・やり直し、書き込み（書き込んで頼む）、（状態の知らせ）、**書き出し**、マスター、スナップ（横の ▾ で吸いつく先を選択）、シャイ（シャイのトラックを隠す）、**オート**（AI を追う。下の 6）、全体（タイムラインを全部表示）、拡大、**EN／日本語**（画面の言葉。1 の 5）。ボタン頭には 1 色の線のアイコンが付き、幅が狭いとアイコンのみに折りたたまれます（マウスを乗せると名前を表示）。押せないボタンもマウスを乗せると理由が出ます |
| 知らせ | 通常の知らせは上のバーの 1 行に表示されます（下線つきはクリック可：保存先を開く等）。**失敗の知らせは右下にも表示され、閉じるまで消えません**（保存失敗時は「今すぐやり直す」ボタン付き） |
| 左：アセット窓 | タブ：セリフ・動画・画像・音声・音楽・TTS済み・エフェクト・キャラ。クリックで見る／聞く →「置く」で今の時刻に配置します |
| 真ん中：プレビュー | 再生中は書き出し済みの動画を表示し、**止めると今のタイムラインの本番と同じ 1 コマ**を表示します（左上に「今のタイムライン」）。描画中も前のコマを表示したままにします（黒くしません）。キャッシュと裏で描く仕組みは下の詳細を参照 |
| プレビューの下（帯） | 左に時刻・コマ番号、真ん中に再生操作（頭へ・1 コマ戻す・再生・1 コマ送る・お尻へ）、右に「プレビュー 等倍／1/2／1/4」と今のカット（丸い札）。ここでマウスホイールを回すと 1 コマずつ（Shift で 1 秒）移動します。プレビューサイズの既定は 1/2 です（本番サイズで描いてから縮小するため描画時間はほぼ同じで転送が軽くなります。PNG と書き出しは常に本番サイズ）。停止中は先の 1 秒ぶんを先読みするため、→ やホイールでのコマ送りがすぐ表示されます |
| 右：クリップ | 選んだクリップの設定（時間・文字・声・パラメータ）。エフェクトは「コードを開く」で編集できます |
| 右：色 | 色の卓（明るさ・コントラスト・ビブランス・彩度）。カットごとに適用されます（カットが無い作品は全体） |
| 右：クリップの「クリップの色」 | 映像・画像・動画化予定のクリップを選ぶと、色の卓と同じつまみ（明るさ・コントラスト・ビブランス・彩度）と「元に戻す」が表示されます。**そのクリップだけ**にかかり（素材読み込み直後・エフェクトより先）、移動・分割・複製しても色が付いてきます。カットの色の卓とは別で両方かかります。全部 1 に戻すとファイルから消えます。色を付けたクリップにはタイムラインにパレットの印が付き、動画化予定の色は「採用」で置く映像クリップにも引き継がれます（タイムラインの小さな絵＝スタートフレームには色は付きません） |
| 右：メタデータ | カット・歌詞・セリフ・ト書きをテキストで編集します（カットはラベル・頭と終わり・つなぐ・分けるも操作可能。下の「カットの段を手で直す」） |
| タイムラインの上 | カット編集の道具のバー（下の「カット編集の道具」） |
| 下：タイムライン | トラック一覧（上が手前）。左上の「＋」とアイコンの 6 つのボタンで TTS・字幕・映像・効果音・音楽・動画化予定のトラックを追加します（種類はマウスを乗せると表示）。クリップを**右クリック**すると解析を実行できます |

トラック名の頭のアイコン（トラック種類の色付き）：エフェクト（きらめき）・映像（フィルム）・字幕（字幕の枠）・TTS（話す人）・効果音（スピーカー）・音楽（音符）・参考の音（カセット）・スクリプト（巻物）・メタデータ（札）。

### プレビューのキャッシュと「裏で描く」

- **ためた絵（フレームキャッシュ）**：書き出しやプレビューで一度描いたコマは作品の `work/cache/frames/` に保存され、直していない区間ではすぐ表示されます（左上に「ためた絵」）。修正したクリップの区間（前後 2 秒、カットのある作品は前後のカットまで）だけ描き直します。
- **裏で描く**（既定は切）：プレビューの下の砂時計ボタンでオン・オフします（切は斜線。切にすると描画中の処理も止まり、入に戻すまで開始しません。描画中は進み具合の %、シーク中は ‖ を表示）。
  - オンの状態で再生を止めて手を離すと、裏で再生位置から先を描いてためます（優先度の低いプロセス。シークやドラッグの瞬間に一時停止し、手を離して 2.5 秒後に再開。編集や書き出しを始めると停止。設定 `mittler.bake.jobs`）。
  - 目盛りの下の**緑の印**がためた区間です。ためた区間から ▶ を押すと、書き出し版の動画ではなく**今のタイムラインの絵**で再生されます（左上に「ためた絵で再生」）。
- **書き出しへの再利用と削除**：書き出しでもためたコマは描かずに使うため、修正後の書き出しが高速です（全部描き直す場合は、書き出し窓の「詳細設定」にある「ためた絵を使わずに全部描く」を使用）。キャッシュを消したいときは Claude に「ためたコマの絵を消して」と頼みます。

## 4. 操作

| 操作 | やり方 |
|---|---|
| 再生・停止 | Space（または再生ボタン） |
| 1 コマ送る・戻す | → ←（Shift で 1 秒）。プレビュー下の再生操作の上でマウスホイール（Shift で 1 秒）、または 1 コマ戻す・送るボタン |
| 頭・お尻へ | Home・End、またはプレビュー下の真ん中にある頭へ・お尻へボタン |
| 動画の長さ | 上のバーの長さボタン（時計のアイコン）→ 秒数指定・＋5秒／＋10秒／＋30秒・最後のクリップに合わせる。タイムライン右の網かけ（動画の外）にクリップを置く・動かすと自動でそこまで伸びます（音楽・効果音では伸びません。Ctrl+Z で元に戻る） |
| 動画の大きさ | 上のバーの大きさボタン（現在のサイズ名を表示）→ FHD 横（1920×1080）・HD 横（1280×720）・SD 横（854×480）・FHD 縦（1080×1920）・正方形（1080×1080）。プレビュー枠と描画がすぐ変わります（Ctrl+Z で元に戻る）。字や重ね絵の位置は画素基準のため変更後にずれを確認してください。再生用動画は書き出し直すまで前のサイズのままです |
| 表示中のコマを PNG で保存 | 上のバーの「PNG」（再生中なら止めてそのコマを保存）。作品の `output/stills/<作品>_<分>m<秒>_f<コマ>.png` に劣化なしで描き直して保存します。上の「保存しました」の文字を押すとエクスプローラーで開きます |
| 時刻を動かす | ルーラーまたはトラックの空いた場所をクリック・ドラッグ |
| 拡大 | Ctrl＋ホイール、または拡大つまみ。F（全体）で全体を表示（開いた直後は全体が幅いっぱいに表示されます） |
| クリップを選ぶ | クリック（Esc で解除）。Ctrl／Shift＋クリックで追加・解除。Shift＋空いた場所をドラッグで範囲選択。Ctrl＋A で全選択 |
| 動かす・長さを変える | ドラッグ・端をドラッグ（コマにそろい、スナップがオンなら近くの目印に吸いつきます）。右の欄の「開始」「長さ」の数値入力でも変更可能（コマにそろって入り、横にコマ番号 `f15`・`75 コマ` を表示。0 や負の長さにはなりません）。選択中のものはすべて一緒に動き、上下にドラッグすると同じ種類の別トラックへ移せます（映像は映像、音は音） |
| 1 コマずつ動かす | Alt＋→ ←（Shift 併用で 10 コマ） |
| 前・次の編集点へ | ↑ ↓（クリップの端に再生位置が移動） |
| スナップ | 上のバーの「スナップ」（磁石のアイコン）または S キーでオン・オフ。横の ▾ で吸いつく先（クリップの端・再生位置・カットの境目・拍・先頭と末尾）を選択。クリップ移動（頭か終わりの近いほう）・端の伸縮・再生位置ドラッグが 8px 以内の目印に吸いつき、黄色い線と「（磁石のアイコン）拍」などを表示します。ドラッグ中に Alt を押している間は反転します（オンなら吸いつかない） |
| 消す | Delete。**リップル削除**（消して同じトラックの後ろを詰める）は Shift＋Delete |
| 取り消し・やり直し | Ctrl＋Z（上のバーの「取り消し」）。やり直しは Ctrl＋Shift＋Z または Ctrl＋Y（「やり直し」）。画面を閉じるまで何回でも戻せます。外（エージェント）がタイムラインを直したあとの Ctrl＋Z は**外の直しだけ**を戻してその旨を通知します（もう一度押すと自分の直しが戻ります） |
| 新しい字幕・セリフ | そのトラックの空いた場所をダブルクリック |
| トラックを足す・消す | 足す：トラック名の上の「＋」とアイコンの 6 ボタン（TTS・字幕・映像・効果音・音楽・動画化予定）。消す：トラック名を押して右の欄の「トラックを消す」または Delete。クリップがある場合は 2 回押すとクリップごと消えます（Ctrl+Z で戻る） |
| トラックを無効にする（残したまま） | 絵のトラック（映像・エフェクト・字幕）はトラック名右の目のアイコンを押すと斜線つきの目になります（描画・書き出し対象外）。音はスピーカーのアイコンを押すとミュートになります |
| シャイ（タイムラインをすっきり） | トラック名右の「·」でシャイの印（おばけのアイコン）を付け、上のバーの「シャイ」で印の付いたトラックを隠す／戻します（表示のみで、描画・書き出しは変わりません） |

### カット編集の道具（タイムラインの上のバー）

一般的な動画編集ソフトと同じ道具です。動画（映像）・音（効果音・音楽・動画の音）・セリフ・字幕・画像に使えます。

| 道具・ボタン | やり方 |
|---|---|
| 選択（V） | 通常の道具。選択・移動・端で長さ調整 |
| カット（C） | クリップをクリックした位置で 2 つに分割（Shift＋クリックでその時刻にかかる全トラックを分割）。分割位置もスナップします |
| スリップ（Y） | 音・動画クリップを左右にドラッグし、配置位置と長さは変えずに素材の開始時刻だけずらします |
| 再生位置で分割（Ctrl＋K） | 選択中クリップを再生位置で分割。未選択時は再生位置にかかるもの全部を分割（Ctrl＋Shift＋K は常に全部） |
| 削除・リップル削除 | Delete・Shift＋Delete と同じ |
| ⇤ 隙間を詰める | 選んだクリップ（またはトラック）のトラックで、最初のクリップから後ろを隙間なく並べます |
| コピー・貼り付け・⧉ 複製 | Ctrl＋C → 再生位置に Ctrl＋V（同じトラックへ）。Ctrl＋D ですぐ後ろに複製 |
| 連動・リンク・リンク解除 | リンクしたクリップ（動画とその音など）は一緒に選択・移動・カット・削除されます（クリップに鎖の印）。連動を切ると 1 つずつ動かせます（音だけずらす等） |
| 動画の音を置く | 選んだ動画から音を取り出し、「動画の音」トラックにリンクして置きます（前に置いた動画用） |

- **音つきの動画を置く**：アセット窓の動画タブで「映像に置く（音もいっしょに）」を選ぶと、音を WAV として取り出し（`assets/video_audio/`）、「動画の音」トラックに**リンクして**置きます。書き出しにもその音が入ります。速さを変えた動画（速さの欄・音ハメ）は音が合わなくなるため、連動を切って音を消すか別に配置してください。
- **音のクリップ**：波形が表示されます。上の角の白い丸をドラッグするとフェードイン・アウトを調整できます（右の欄の数値と連動）。
- **ト書き・セリフ・歌詞など（下のメタデータの段）**：真ん中をつかんで移動、端で長さ調整、空いた場所をダブルクリックで追加、選択して Delete で削除できます。段名の横の **＋** で再生位置に追加でき、右クリックでも「ここに足す・文字を直す・消す」が選べます。クリックすると右の「メタデータ」欄にその行が表示され、文字を編集できます。

### カットの段を手で直す

メタデータの「カット」段を直接編集する操作です。

- **境目を動かす**：カットの端をドラッグします。隣のカットの端も一緒に動くため、すき間や重なりは発生しません。右の「メタデータ」欄の頭・終わりの数値でも変更できます。
- **分ける**：カット上でダブルクリック（その位置で分割）、段名横の ＋（再生位置で分割）、右クリックの「ここで分ける」、欄の「再生位置で分ける」が使えます。
  - 新しいカットのラベルは自動で決まります（`12` → `12b`、すべて数字で最後のカットなら `41` → `42`、数字の無いラベルは `hook` → `hook-2`）。
- **つなぐ・消す**：欄の ←（前のカットとつなぐ）・→（次のカットとつなぐ）・×、右クリック、または選択して Delete（前のカットに吸収）。
- **ラベル・歌詞・ト書き**：右の「メタデータ」欄のカットタブで編集します。
- **カット参照の自動追従**：カットのラベルを参照しているもの（色の卓・カットごとのエフェクト・映像クリップのカット）は連動して更新されます。
  - ラベルを変えると参照先も一緒に変わります。
  - 分けると後ろのクリップは新しいカットへ移り、またがる色の卓などは両方のカットに同じ値が入ります。またがる映像も同じ位置で分割されます（映る絵は変わりません）。ただし、音ハメの表のある映像・最後のコマに着地する映像・動画化予定クリップがまたがる位置は、分けると絵が変わるため分割せずに通知します。
  - つなぐと消えるカットのものは残るカットへ移ります（両方にある色の卓などは残るカットの値が使われます）。いずれも Ctrl+Z 1 回で戻せます。
- **映像クリップとのずれと合わせ方**：カットと映像は別管理のため、カットの境目を動かしても**映像クリップは動きません**。境目と映像クリップの端がずれると、カットに警告の印（三角のアイコン）が表示されます（ずれた区間はそのカットの映像が無い時刻になります）。
  - **映像をカットに合わせる**：警告の付いたカットの欄のボタン・右クリック・境目移動後の上のお知らせ（「ここを押すと映像をカットに合わせます」）、または欄の上の「映像を全部合わせる」を実行します。
  - そのカットの映像クリップの頭をカットの頭へ、終わりを次のカットの頭へそろえます（隣どうしを合わせると前の映像の終わりと後ろの映像の頭が境目で一致します）。素材の時刻は変えない（頭を動かすときは「素材の頭」もずらす）ため、境目の外の絵は変わりません。Ctrl+Z 1 回で戻せます。
  - 素材が足りない（伸ばすと素材の頭より前・終わりより後ろになる）・素材の長さが分からない・音ハメの表のファイル・最後のコマに着地・弾んで出る画像・動画化予定クリップの場合は、理由を表示して何も変更しません。
- **カット・ト書きの段が無い作品**：段の名前の並びの一番下にある「＋ カットの段」「＋ ト書き」で作成します。空のカットの段をダブルクリックすると最初のカット（全体）が作られ、全体にかけていた色の卓はカット 1 のものになります。
- **動画化予定・映像からカットを作る**：
  - 動画化予定クリップの欄の「この範囲をカットにする」を使うと、カットの中なら分割し、カットの無い場所なら追加します（ラベルは予定の名前）。
  - 「採用するとき、この範囲をカットにする」にチェックを入れると（作品ごとに記憶）、「採用」「全部採用」「最新の動画を全部採用」でカットも追加され、置いた映像クリップのカットもそのラベルになります（Ctrl+Z 1 回でまとめて元に戻る）。
  - 映像クリップの欄にも「この範囲をカットにする」があります（カットの無い映像クリップのみ）。

### 自動保存とコミット

- **自動保存**：編集後約 0.35 秒で `*.cut.json` へ自動保存されます。文字入力欄は欄から抜けたとき（Enter・Tab・ほかをクリック）に反映されます。
- **手動保存と失敗時**：Ctrl＋S で保留中の保存をすぐ実行します（変更が無ければ「保存済みです」と表示）。保存に失敗すると「保存できませんでした…」と右下に通知が出て数秒おきに自動リトライします（編集内容は画面に残り、「今すぐやり直す」も押せます。成功すると「保存できました」と表示）。
- **別ファイルの保存**：キャラ設定は「保存」ボタン、エフェクトのコードは「保存」または Ctrl＋S のときだけ保存されます。
- **git コミット**：エージェント（Claude Code）が作業のたびにコミットします（開始前に画面で直した分があれば先に別コミットに分けます。「コミットしないで」「まとめて」と指示すれば従います）。プッシュは頼まれたときだけ行います。戻したいときは「戻して」と言えばそのコミットを取り消します。

## 5. よくやること

### 画像・動画を置く

アセット窓で選んで「置く」を押すと映像トラックに入ります。画像はクリップの欄で寄り（カメラ）も設定できます。

### キャラ

「キャラ」タブでキャラを作成します。よく使うキャラをプリセットにしておくと、「＋プリセットから」で立ち絵（差分も含む）・キャラ設定・声ごと作品に追加できます（プリセットの置き場はこのリポジトリの隣の `presets/characters/`。インストールガイドの 6）。

### セリフ（TTS）

1. 「キャラ」タブでキャラを作成します（名前・立ち絵・キャラ設定・Gemini の声とスタイル／VOICEVOX の話者）→「保存」。
2. トラックを足す「＋」（話す人のアイコン）で TTS トラックを追加します（キャラを選択）→ 空いた場所をダブルクリック。
3. 文を書きます（Gemini は演技タグもそのまま記入）→ 必要ならエンジン・モデル・声を変えます（空欄はキャラ設定の値）。Gemini ではスタイルの下の「このシーンの演技」にそのセリフだけの演技を書けます（スタイルの後ろに ` / ` でつないで送信）→ **生成**。
4. テイクが積まれるので、再生ボタンで確認して使うテイクを選びます（クリップの長さはテイクに自動調整されます）。

- **まとめて生成**：アセット窓の「セリフ」タブ最上部（または TTS トラックの欄）の「未生成のセリフを全部生成（N）」。文が入っていてテイクが無いセリフを時間順に 1 本ずつ生成します。もう一度押すと現在の 1 本で停止し、3 本連続で失敗すると自動停止します。Ctrl+Z は 1 本ずつ戻ります。
- **字幕にする**：同じ並びの「セリフから字幕を作る（N）」。しゃべる文（タイムラインの表示名ではない方）から字幕を作ります。演技タグ `<…>` は外され、無音だけの行（……。）は作りません。時間はセリフと同じになり、もう一度押すと時間を合わせ直します（手で直した字幕の文は保持）。セリフを選んでいれば選んだものだけ対象になります。
- **全部作り直す**：その下の「↻ 全部のセリフを再生成（N）」。文が入っているセリフすべてを新しいテイクで作り直します（前のテイクは残るため選び直せます）。誤操作防止のため、1 回目は「もう一度押すと…」になり、5 秒以内にもう一度押すと開始します。
- **接続先と鍵**：Gemini TTS は文字を Google に送信します（鍵はその PC の資格情報マネージャーの `ps:GEMINI_API_KEY`。インストールガイドの 5）。VOICEVOX はその PC で起動している VOICEVOX を使用します。

### 動画化予定

1. 映像のすぐ下の動画化予定トラックをダブルクリックして予定クリップを作ります。
2. 右の欄でスタート／エンドの絵を選び（アセット窓の画像から「スタートの絵に」でも指定可）、生成プロンプト・動画のプロンプトを書きます。
   - キャラ参照は `@import char(キャラのid) as 名前;`（欄の下の「＋キャラ」でも挿入可）。
   - 欄の下に参照チップ（立ち絵サムネと「参照画像」番号）が出ます。赤は誤りなのでマウスを乗せて理由を確認してください。キャラ設定の「外見」「立ち絵の差分」も使われます。
   - 映像がまだ無い区間は、プレビューでスタート→エンドの絵を仮表示します。
3. **静止画の生成**：「生成」でその絵を作ります（Codex、1〜2 分）。生成後はテイクに積まれ、サムネを押して切り替えられます（警告の三角アイコンはプロンプトや参照が一部届かなかった印）。生成は編集画面を開いている PC で動くため、その PC の Codex CLI にログインしている必要があります。
4. **動画化（H3）**：動画の欄の「動画化」を押すと、開始・終了の絵とプロンプトを H3（動画生成）のキュー（Google ドライブの `H3_tasks`、受け渡し形式は `docs/H3受け渡し契約.md`）に投入します。キューを処理する側（H3 ランナー、Mittler 外）が動画を返すと動画テイクが積まれます。
   - **下書き**：「下書き」はステップ数を減らして高速に生成します（下書きステップ欄の初期値は 10、本番は 25）。シードは下書きも本番も同じなので、気に入った下書きは「動画化」を押せば同じシードで本番になります。別の動きを引きたいときは「変える」でシードを変更します（変えなければクリップごとに固定値）。下書きテイクには「下書き 10step」の印が付きます。
5. **確認と採用**：
   - テイクのサムネか再生ボタンを押すと、生成動画そのものが中央プレビューで音つき再生されます（左上に「テイク …」）。一時停止・再生位置・閉じる（×）はテイク行で操作します。タイムラインを再生・シークすると閉じて元の絵に戻ります。
   - テイクを押して選ぶと、採用前でもタイムラインのその位置に映るため、前後とつなげて見比べられます。
   - 「採用」で映像トラックの同じ時間に配置され、プレビューと書き出しに反映されます。
   - まとめて置くときは、動画化予定トラック名を押して「選んでいるテイクを全部採用」、またはタイムライン上の道具バー（およびトラック欄）の「最新の動画を全部採用」を使います。
6. **口パク（歌用）**：エンジンを「H3 ref2va」にし、動画プロンプトに `@import audio(here);`（このクリップ時間のセリフ）と書きます。
   - **ref2va は歌専用です。アニメのしゃべりは fl2va で絵を先に作り、セリフはあとで合わせてください（アフレコ）。**
   - 書き方と成功例は `docs/技術集/07b_口パク_ref2va_話者の指定と成功例.md` を参照してください。
   - ファイルの一部を使う場合は `@import audio("assets/voice/…wav", 1.20s, 4.50s);`。音声は 1.5〜14.5 秒。ref2va は開始の絵が必須で、終了の絵は使いません。

### 解析（クリップを右クリック）

描いている PC の解析用 python（インストールガイドの 9。GPU のある PC 向け）で解析し、作品の `assets/analysis/<クリップ>_<種類>_<日時>/` に出力します。処理は 1 つずつ順番に動きます。

- **音のクリップ**：拍を取る（→ メタデータ「ビート（…）」に入りスナップにも効く）・文字起こし（→ メタデータ「文字起こし（…）」、単語の時刻はファイル）・ボーカルと伴奏に分ける（→ ミュートの音トラック 2 本）
- **セリフのクリップ**：文字起こし（→ セリフのメタデータ）
- **映像のクリップ**：人のポーズ（YOLO11）・人のマスク（白＝人の動画）
- **画像のクリップ**：ポーズ・マスク・人の切り抜き（透明つき PNG。画像タブから配置可能）
- タイムラインに入れられないもの（ポーズ・マスク・切り抜き）は右下に「アセットに回収しました」と通知します。タイムラインに入った結果は Ctrl+Z で戻せます。

### フッテージを伸ばす（⟷）

映像クリップを選ぶと右の欄に「⟷ 伸ばす」が表示されます。伸ばす先（次のクリップの頭まで・動画化予定の長さ・秒数）を選び、次のどちらかを選びます。

- **ゆっくりにして伸ばす**：同じ中身を速度を落として伸ばします。
- **最後のコマで止めて伸ばす**：素材が足りない区間を最後のコマで止めます（リンクした音も同じ終わりまで）。

映像クリップを 2 本以上選択している場合は「それぞれ次のクリップまで」でまとめて処理できます。

### 速さ・音ハメ

映像クリップを選ぶと右の欄に「速さ（倍）」と「音ハメ」が表示されます。

- **音ハメ（自動）**：動画内の動きの止まり・切り返し（キメ・着地）を検出し、タイムラインのビートに合うようにクリップ内で速度を変えます（Attention ダンスMV の手法）。速さの上限・下限・なめらかさ・裏拍にも合わせるか・終わりを動画の終わりにそろえるかは「音ハメの設定」で調整します。
- **グラフ**：横軸が曲の時刻、縦軸が映す動画の秒です。縦線が拍、橙の点線が動きのアクセント、緑の丸が拍に合った点、下の帯が速度（赤は上限・下限外）を表します。白い点はドラッグで修正でき（拍とアクセントに吸いつく、Alt で無効）、ダブルクリックで追加・右クリックで削除します。
- タイムラインのクリップには速度線（黄色、中央点線が 1×）と速度幅のバッジが表示されます。「一定の速さに戻す」で解除できます。

### 字幕・効果音・音楽

- **字幕**：字幕トラックをダブルクリックして文字を入力します（改行で 2 行）。フォント・大きさ・色・縁・位置を変更でき、「初期の位置に戻す」もあります。
- **効果音・音楽**：アセット窓の音声・音楽タブから「置く」で配置します。音量（`gain`）やフェードはクリップの欄で調整します。

### Suno の曲（AI に作ってもらう）

1. 音楽トラックの空いた場所をダブルクリックします（既存の音楽クリップなら欄の「Suno の曲にする」）。
2. 右の欄の「Suno の曲」に曲の説明（歌詞・スタイル・タイトル・インスト指定も可）を書き、Claude Code に「この曲を作って」と頼みます。Claude がプロンプトを確認してから Suno で生成します（生成クレジットを消費、30 秒で 5 ほど）。
3. できた曲はテイクに並びます（この時点ではファイルを取得しません）。**試聴は「suno.com で聞く」**を押して、いつものブラウザで suno.com の曲ページを開いて聴きます。
4. 気に入ったら「採用」を押します（**ダウンロード用クレジットを 1 つ消費**する確認が曲ごとに 1 回出ます）→ OK で「採用待ち」になります。
5. Claude Code に「採用した曲を取ってきて」と頼むと、Claude が WAV を取得してクリップに入れ、拍と曲構成もメタデータへ登録します（音ハメ・スナップにそのまま効きます）。ダウンロード URL は 1 時間で切れるため、採用後すぐ依頼してください。
- ブラウザ版の suno.com で作った曲は、従来どおりダウンロードして `assets/` に置きます（拍は解析で取得。Suno の解析は API 生成曲のみ対応）。ボーカルと伴奏も解析で分離できます。

### 色・エフェクト

- **色**：右の「色」タブのスライダーで調整します。ドラッグ中はおおよその色を表示し、離すと本番エンジンで描き直します。
- **エフェクト**：アセット窓の「エフェクト」タブで説明を見て「この時刻に置く」を押します。コードはそこ、またはエフェクトクリップを選んで「コードを開く」から編集でき、保存するとすぐ描き直されます。パラメータはクリップの欄で調整します。新しいエフェクトは Claude に「〇〇なエフェクトを作って、△秒から□秒にかけて」と頼むのが早いです。

### HTML のレイヤー（2026-11-18）

「部品の置き場」から「HTML のレイヤー」を「作品に入れる」と、作品の `html/` にひな形（文字の動き・three.js の光る粒・立体の形）が入ります。Claude に「〇〇な文字の動きを HTML のレイヤーで作って、△秒から」と頼むと、場面に合わせたページを書いて配置してくれます。描く python に Playwright が必要です（インストールガイドの 16）。

### 3D の演出（2026-11-13）

「エフェクト」タブの一番下にある「部品の置き場（作品にまだ入っていないもの）」から選んで「作品に入れる」を押すと、上の一覧に表示されて「この時刻に置く」で配置できます。名前の横の「3D」の印が目印です。

- **GPU の 3D（その場ですぐ描ける）**：**3D の板**（絵・動画・今の画面を板にして輪・壁・扇に並べて回す）・**奥行きのある粒子**・**光の筋**（ワープ・回る光の帯・のぼる筋）。描く PC の python に moderngl が必要です（インストールガイドの 14）。
- **Blender の 3D**：Blender で描く本格的な 3D（反射・影・ガラス・金属）。作品に入れると `3d/` に場面のひな形（ロゴの組み上がり）が入り、Claude に「3d/logo.py を〇〇にして」と頼んで編集できます。
  - 描いた絵は作品の `work/3d/` にキャッシュして使い回します。止めたコマにキャッシュが無ければ下描き（荒い絵）を数秒で描画します（プレビュー左上に「Blender の 3D を描いています」）。
  - 本番品質の絵は「PNG」または書き出し時に描かれます（書き出しでは区間分割前に Blender でまとめて描画し、窓に「Blender で 3D を描いています」と表示）。
  - クリップの欄には「描き直す」「ためた絵を消す」「場面を開く」があります。Blender が必要です（インストールガイドの 14、設定 `mittler.blender.path`）。
- 3D を使った作品は、別の PC や別の GPU で描くと画素値がわずかに異なることがあります（同じ PC・同じ設定なら同じ絵になります）。

### 書き出し

上のバーの「書き出し」を押し、品質・範囲（全体か一部）・ファイル名を選んで「書き出す」を押すと、`output/<名前>.mp4` に出力されます。

- **中止**：書き出し中は「中止」で止められます（再生用動画を作成している途中でも止まります。ただし最終仕上げ＝音声合成段に入ってから押した場合は、止めずに仕上げて「できた」と通知します）。
- **サイズ確認と出力表示**：幅か高さが奇数の作品は描画前に理由を出して停止します（上のバーの大きさボタンで偶数にしてください）。完了後は「フォルダで表示」でファイル選択状態のエクスプローラーが開きます。窓の下には出力概要（例：`1920×1080・30fps・MP4`）が出ます。
- **品質とサイズ**：
  - 「下書き」（24fps なら 12fps）・「下書き（速い）」（1/4）はフレームを間引いて高速出力します（確認・共有用。音声はすべて入り、ファイル名に `_draft` が付き、音量自動調整はしません）。
  - 下書きのときだけ「サイズ」（1/2・1/4）を選べますが、エフェクトが元画素サイズ前提のため元の大きさで描いてから縮小します（ファイルは軽くなりますが時間は変わりません）。
- **プレビュー連携と詳細設定**：「完了後、この動画をプレビュー再生に使う」にチェックしておくと、完了後にその動画で再生されます（VS Code は MP4 を再生できないため WebM を作成）。同時処理数（並列数）と保存先フォルダを開くボタンは「詳細設定」を開くと表示されます。各項目の細かい説明はマウスを乗せると出ます。

### マスター書き出し

上のバーの「マスター」（トロフィーのアイコン）から 60fps の最終版を書き出します。窓には「画質」「範囲」「ファイル名」と出力の 1 行が表示されます。**画質**は作品ごとに記憶されます。

- **標準**（高画質化なし・速い）：作品と同じ大きさ（FHD なら FHD、縦長ならそのまま）で 60fps にします（映像素材は 60fps に補間）。通常書き出しの約 2 倍（30fps 作品）の時間で終わり、4K 未対応のエフェクトがあっても止まりません。このとき映像クリップ欄の「マスター画質」は無視されます（窓に「クリップごとの画質の指定は「標準」では使われません」と表示）。
- **高画質（アニメ）**：4K で描いてから FHD に縮小し、細部までくっきり仕上げます（映像素材は先に 4K 拡大して 60fps 補間）。アニメ・イラスト向けで輪郭がくっきりしますが、写真の細かい模様は塗ったように平らになります。通常の約 10 倍の時間がかかります。
- **高画質（実写）**：同じく 4K から縮小します。写真・実写・写真調の生成動画向けで、ヒョウ柄・スパンコール・ラメの粒を元の形のまま残します。アニメより時間がかかります（拡大に約 11 倍）。
- **クリップごとの画質指定**：未選択の作品は高画質（アニメ）になります。写真とアニメが混在する作品では、映像クリップを選んで右の欄の「マスター画質」（作品の設定／高画質（アニメ）／高画質（実写））で個別に変えられます。変えたクリップがあると窓に「一部のクリップは別の画質で書き出します」（マウスを乗せると内訳表示）と出ます。
- **キャッシュと詳細設定**：画質を変えると対象素材の高画質化と 60fps 化はやり直しになりますが、前のキャッシュも残るため戻せばすぐ使えます。「詳細設定」を開くと、同時処理数・「4K に未対応のエフェクトがあっても書き出す」（高画質時のみ）・キャッシュ（サイズ表示と「削除」、「キャッシュを使わずに作り直す」）・保存先フォルダを開く、が操作できます。
- **進捗と技術詳細**：書き出し中は「準備 → 高画質化 → 60fps 化 → 書き出し → 仕上げ」の段階と割合・残り時間が表示されます。止まったときは理由と対処が 1〜2 行で出、エフェクト名一覧などは「詳細」で確認できます。技術的な内容（Real-ESRGAN・RIFE・キャンバス倍率など）はツールチップとインストールガイドの 12「アップスケールのモデル」「アップスケールなし（60fps だけ）」を参照してください。

### 動画 1 本を高画質にする（作品は要らない）

コマンドプロンプトで次を実行すると、マスター書き出しと同じ処理で 60fps・短い辺 1080 の MP4 に変換できます（`none` はサイズそのまま 60fps 化のみ）。

```
<Mittler の場所>\tools\enhance.cmd <動画> [<出力.mp4>] [--upscale anime|real|none]
```

- 選べるのはアップスケール方式のみ：`anime`＝アニメ（省略時の既定）・`real`＝実写・`none`＝なし。
- 出力先を省略すると、元動画の隣に `<名前>_enhanced_<方法>.mp4` が作成されます。
- Real-ESRGAN・RIFE が必要です（入れ方と詳細はインストールガイドの 12「動画1本を高画質にする」）。

## 6. Claude Code に頼むとき

### 始め方と頼み方の例

**VS Code で作品のフォルダを開き**（ファイル → フォルダーを開く → 作品のフォルダ）、右側に Claude Code を開いて話しかけます。

- Claude Code は起動時に作品の `CLAUDE.md` から作品の `AGENTS.md`（正本の場所・中身・決まり）と Mittler の AI 用ガイドを読み込み、親フォルダに `CLAUDE.md` があればそれも読み込みます（ファイル単体で開いた状態だと読まないことがあります）。
- Claude Code 以外のエージェントは作品の `AGENTS.md` を読みます（話しかけるたびに編集画面の今を添えるフックと書き込みの受け渡しは Claude Code 向けです）。
- 作品外のガイドを取り込むため、**作品ごとに最初の 1 回だけ「読み込んでいいか」と聞かれます → 許可してください**。

頼み方の例：

- 「12秒のところに、画面がぶるっと揺れるエフェクトを足して」
- 「セリフの字幕を全部、ト書きのセリフから作って」
- 「書き出したものを見て、字幕が切れているところを教えて」
- 「区切りがいいのでコミットして」
- 「plan_03 と plan_04 を動画化して」「全部下書きで動画化して」（プロンプト作成から H3 投入まで。投入前に本数を確認してきます）
- 「この曲の拍を取って」「このセリフを文字起こしして」（右クリックの解析と同じ。結果もタイムラインに入ります）
- 「music_01 の曲を Suno で作って」「採用した曲を取ってきて」（Suno の曲。作成前にプロンプトとクレジットを確認してきます）

> **注意**：動画化や解析を Claude に頼むときは、**その作品の編集画面を開いたままにしてください**（Claude は編集画面のサーバーへ依頼し、結果の取り込みも編集画面が行います）。また、画面で編集中に同時に Claude へタイムライン編集を頼むとあとから保存したほうが勝つため、どちらか一方ずつ操作してください（Claude の直しが気に入らなければ、編集画面の Ctrl+Z でその直しだけを戻せます）。

### 画面に書き込んで頼む

1. プレビューを止めた状態で、上のバーの「書き込み」（ペンのアイコン）を押します。
2. ペン・矢印・丸・四角（色・太さ変更可）で画面に直接描きます（Ctrl+Z で線を 1 本戻す、Esc でキャンセル）。
3. 「AI に渡す」（Enter）を押します。
   - **Claude Code**：横の Claude Code の入力欄へカーソルが移るので、そのまま「ここの字を小さくして」のように話しかけると、書き込んだ画面が 1 回だけ添えられます。
   - **ほかの AI（Antigravity・Codex など）**：描いた画面の場所と短い頼みの文がクリップボードにコピーされるので、AI のチャットに貼ってから頼みを書きます。貼らなくても、作品の `AGENTS.md` を読む AI は `.mittler/state.json` から見つけます。

書き込んだ画像は作品の `.mittler/annotations/` に保存され、プレビュー右下に新しい順で 3 つまで縮小表示されます（「AI に話しかけると届きます」→「AI に届きました」、絵を押すとその時刻へ移動、右上の × で閉じる。読み直しても残ります）。

### 編集画面の共有・オート追従・できる操作

- **編集画面の今を自動共有**：話しかけるたびに、選んでいるクリップ・今の時刻・その時刻に映っているもの（停止中ならその 1 コマの絵も）が自動で Claude に渡ります（作品作成時に `.claude/settings.json` へフックが入ります）。クリップを選んで「これの字幕を短くして」、止めて「ここの色をもう少し明るく」と指示できます。別タブで別作品の編集画面を触っているときは、そちらの情報が「いま手前は別の作品」付きで渡ります。
- **AI を追う（オート）**：上のバーの「オート」（マウスのアイコン、既定オン・オン時は色付き）がオンのとき、Claude がタイムラインを直すと直したクリップの中央へ再生位置が飛び、数秒間光ります（プレビューもその絵に切り替わります）。停止中のみ移動し、再生中やドラッグ・入力中は光るだけです。選択中のクリップは変わりません。なお、Claude は頼まれない限り編集画面で開いている作品を直接直します（写しで作業すると画面で見えないため）。
- **ボタン操作の代行**：Claude は Suno の「採用」と H3 の動画化以外、画面のボタン操作をたいてい自分で実行できます（セリフ生成・字幕作成・テイク選択・採用・書き出し・PNG・音ハメ・カットの段・カット編集）。また、再生・時刻移動・クリップ選択・タブ切替・拡大・言語切替・書き出し窓を開くといった画面操作も行えます（作品は変更しません）。
- **セリフの速さ**：セリフクリップの欄にある「速さ（生成のあと）」（0.5〜2、空欄はキャラ設定の値）は次に生成したテイクから反映されます。音声の長さでクリップが伸び、同じトラックの次のセリフと重なるとクリップ右上に注意の印が出ます。

## 7. 困ったとき

| 困ったこと | 対処方法 |
|---|---|
| 再生しても黒い・音が出ない | 再生用の動画が無い（新しい作品）か MP4 のままです。一度「書き出し」で「完了後、この動画をプレビュー再生に使う」にチェックして書き出してください。止めたときの 1 コマは常に表示されます。再生用動画が無い間は描いたコマを順に表示して再生します（上のバーに通常色の通知が出るだけで、止めると消えます） |
| 「描画サーバーを起動しています…」のまま | 設定の python・ffmpeg の場所を確認します（`python setup\mittler_setup.py` で確認できます） |
| 画面の上に赤い箱「素材が見つかりません：…」「… 秒の 1 コマを描けませんでした」 | その時刻の 1 コマが描けませんでした。箱の文は選んでコピーできます（「コピー」ボタンも）。Claude Code には、次に話しかけたときに自動で伝わるので「エラーを直して」と頼めます。素材が無いときは、その絵ができる・置かれると消えます |
| 上のバーに黄色・赤の知らせ（「再生用の動画を再生できません」など） | 知らせを押すと「知らせとログ」の窓が出て、全文と最近の記録（動画の読み込み・描画・保存の失敗など）を見られます。「コピー」で全部をクリップボードに入れて、AI や Issue に貼れます。再生用の動画が読めなかったときは、次に再生したとき・ファイルが置きかわったときに自動で読み直します |
| 「設定された python が見つかりません」「設定された python … で … import できません」 | 設定 `mittler.render.python` のパスか中身が違います。修正して「ウィンドウの再読み込み」を実行してください |
| 「この PC で描画できる python … が見つかりません」 | この PC に描ける python がありません。設定 `mittler.render.python` に numpy・opencv・Pillow の入った python を指定する（1-3）か、描ける PC に Remote-SSH で接続して開いてください |
| 「アクセスが拒否されました」（ほかのアカウントが作ったフォルダ・Python） | そのフォルダと Python を、自分のアカウントで読み書きできるように権限を変更します（`icacls`） |
| 直したコードが出ない | ファイルを保存したか確認してください。Mittler 本体を更新した場合は「ウィンドウの再読み込み」を行います |
| git が「dubious ownership」 | ほかのアカウントが作ったフォルダです。`git config --global --add safe.directory "<そのフォルダ>"` を実行します |
| 画面がおかしい・Claude が作った絵やテイクが出ない | 上のバーの「読み直す」（保存完了を待ってから画面のみ再読み込み、再生位置と選択クリップは維持）を押します。直らなければ「ウィンドウの再読み込み」を実行します（タイムラインは保存済みなので消えません） |
| プレビューの 1 コマが出ない・書き出したあとの再生用の動画が読めない | 「ウィンドウの再読み込み」を試します（複数作品を同時に開いても作品ごとに別の描画サーバーで描きます）。直らなければ Claude に「プレビューが出ない」と伝えてください |
| 書き出しで「注意：ピークが上限…をわずかに超えました」（`LOUDNORM_WARN`） | 音量そろえ（loudnorm）を 1 回やり直してもピークが目標をわずかに超えた状態です。書き出し自体は完了しています。気になれば Claude に確認してください |
| 解析が「ブロックされました」「WinError 4551」で失敗 | Windows のスマート アプリ コントロールが初回読み込み部品を止めています。もう一度同じ解析を頼むと通ることが多いです |
| 解析が動かない | 解析は解析用 python（インストールガイドの 9、設定 `mittler.analysis.python`）がある PC でのみ動きます。無い PC からは、入っている PC に Remote-SSH で接続して開いてください |
| 動画化したのにテイクが来ない | 動画は H3 のキューを流す側（Mittler 外）が生成します。編集画面を開いたままにしておくと完了時にテイクへ入ります（閉じていた場合は次回開いたときに入ります） |
| 保存できていません、と右下に出たまま | 自動でやり直しています。「今すぐやり直す」を押してください。続く場合はタイムラインファイルを別アプリが開いていないか・書き込み可能なフォルダかを確認します |

もっと細かい仕様については、`docs/タイムライン形式.md`（ファイルの形）、`docs/エフェクトの書き方.md`、`README.ja.md`（英語は `README.md`）を参照してください。
