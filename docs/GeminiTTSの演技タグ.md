# Gemini TTS の演技タグ（ボイスタグ）の使い方

Mittler のセリフ（TTS クリップ、エンジン `gemini`）で声に演技を付ける書き方です。Gemini TTS は、文を**一字一句そのまま読む台本**として扱います。

文中に置く山かっこの**演技タグ**は、その位置で一度だけ起きる「音や間」を鳴らします。タグの無い文は平坦な読みになりやすいため、適切に活用してください。

## 使ってよいとき（AI への決まり）

- **ユーザーの事前許可があれば、AI は Gemini TTS を好きなときに使って構いません。作り直し（リトライ）も可です。**
  - 許可は作品の計画を提示したときにまとめて得ます（AI 用ガイドの「作品づくりの進め方」）。
  - Gemini TTS はテキストを Google に送信します（API キーは表示しないこと）。
- 生成は編集画面の「生成」「未生成のセリフを全部生成」、または API（`python .mittler/api.py . …`。AI 用ガイド 7.53）から実行します。

## 2 つの指定の分け方

| 指定 | 記述先 | 中身 |
|---|---|---|
| **声の基本（スタイル）** | キャラ設定の `tts.gemini.style`（キャラの声の原文。変更しない） | 声の質・年齢感・いつもの話し方 |
| **その場面だけの演技** | TTS クリップの `delivery_style` | ささやき声で・早口で・怒って・照れながら、など**続く**演技（Gemini にはスタイルの後ろに ` / ` でつないで送信） |
| **一度だけの音や間** | 文中の演技タグ `<…>` | 下の一覧にある笑い・息・ため・驚きなど |

> 続く演技（ささやく・早口など）は文中に書かず、タグにもしません。必ず `delivery_style` に記述します。

## タグの書き方

- **形式は英語の山かっこだけ**：`<short pause>`・`<chuckle>` のように記述します。日本語の文中でもタグは英語です。
- **一度だけの音・間**：閉じタグ・入れ子・属性は付けません（`</laugh>`・`<laugh intensity="2">` は不可）。
- **下の一覧にあるタグだけを使用**：一覧に無い文字列はそのまま文字として読み上げられます。
  - `<happy>`・`<angry>` のような**気分の名前のタグはありません**（タグは「音」のみ）。
  - 角かっこの古い形式（`[laughs]`）は使いません。
- **上限**：タグの種類・数に Mittler 側の上限はありませんが、同じ笑いを続けすぎると不自然になります。
- **字幕との連携**：編集画面の「セリフから字幕を作る」は、文から演技タグを外して字幕を生成します。

## 使えるタグ（公式の一覧）

| 種類 | タグ | 使いどころ |
|---|---|---|
| 間 | `<short pause>` | 考える間・ため・小さな切り替え・オチの直前（いちばんよく使う） |
| 間 | `<long pause>` | 大きな区切り・余韻 |
| 息 | `<breath>` | 長い文の前・気持ちを整える |
| 息 | `<heavy breath>`・`<pant>` | 驚いたあと・走ったあと・緊張・息切れ |
| 息 | `<exhales>`・`<sigh>`・`<phew>` | ふうっと吐く・ため息・ほっとする |
| 息 | `<pff>` | 呆れ・ちょっと吹き出す |
| 笑い | `<chuckle>` | ふふっと控えめ（いちばん使いやすい） |
| 笑い | `<giggle>`・`<laugh>`・`<snicker>`・`<cackle>` | クスクス・はっきり・含み笑い・高笑い |
| リアクション | `<gasp>` | はっと息をのむ（驚き・ひらめき） |
| リアクション | `<tsk>`・`<groan>`・`<argh>`・`<cheer>`・`<snort>` | ちぇっ・うぅん・うわー・やったー・鼻で笑う |
| 強い気持ち | `<sob>`・`<cry>`・`<whimper>`・`<yawn>` | 涙で詰まる・泣く・弱々しい・あくび |
| 特別 | `<cough>`・`<throat-clearing>`・`<sneeze>` | 咳・咳払い（「コホン、では発表します」）・くしゃみ |

## どこに入れるか

- **基本位置**：文と文の間（「。」「！」「？」の直後、次の文の頭）に入れます。
- **主な入れどころ**：
  - 冒頭のリアクション：`<gasp>`・`<chuckle>`
  - 考えてから答える所：`<short pause>`
  - 話題が変わる所：`<short pause>`・`<breath>`
  - オチやからかいの前後：前に `<short pause>`、後に笑い
  - 長い文の前：`<breath>`
  - 一段落した所：`<phew>`・`<sigh>`
  - 決めゼリフの直前：`<short pause>`
- **禁止事項**：
  - タグどうしを直接つなげない（`<sigh><short pause>` は不可。`<sigh> そっか。<short pause>` は可）。
  - 固有名詞・数字・単語の途中に入れない（前後は可）。
- **タグ以外の表現との併用**：
  - 「、」「…」「——」でためらいを表現する。
  - 「えっと」「あー」「うーん」など話し言葉のゆらぎを使う。
  - 英単語の強調は大文字（`VERY`）にする。
- **効果音との使い分け**：拍手・足音・音楽などの効果音はタグにせず（タグは人の声のみ）、音のトラックに置きます。

## 例

- `<gasp> え、本当に？<short pause> すごいじゃん、おめでとう！<chuckle>`
- `うーん、そうだなあ…<short pause> あ、そうだ！<breath> 今日はこれを作ってみよう。`
- `<phew> やっと終わった〜。<sigh> 今日はほんとによく頑張ったね。`
- ナレーション：`<breath> 頭脳と手の仲介者は、<short pause> 心でなければならない。`

## 確かめる

- **聴いて確認・リトライ**：生成したテイクは実際に聞いて確認します（AI は文字起こしの解析で読みまちがいや、タグが文字として読まれていないかを確認できます）。不自然なら作り直して構いません。
- **読み辞書**：読みまちがいがあった場合、ユーザーが単語と読みを指定したときだけ、作品の `pronunciation.json` に追加します。
- **重なり確認**：音声の長さに応じてクリップが伸びるため、隣のセリフと重なっていないかタイムライン上で確認します。

> 出どころ：作者のワークスペースの Gemini TTS の決まり（公式のタグの一覧と使い方をまとめたもの）と、Mittler の TTS の作り（`tools/gen/gemini_tts.py`・AI 用ガイド 8）。タグの一覧は Gemini TTS のバージョンで変わることがあります。
