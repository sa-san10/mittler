# 02 顔・口・手の検出と、体の動き（ポーズ）

## 1. 顔と口：YuNet（OpenCV）
- **何のため**：文字を顔・口にかぶせない（置き場所を自動でよける）、主役の顔の位置の取得、SAM 2 の手がかり生成（01）、ソロの人物の見分け（顔の大きさ）。
- **しくみ**：`cv2.FaceDetectorYN`（モデル `face_detection_yunet_2023mar.onnx`）で、顔の箱・スコア・口の位置を検出します。
  - **偽マリア**：実写風の絵では顔の大きさによって検出できたりできなかったりするため、**3 つのサイズ（1920・960・480）で検出**し、重なりはスコアの高い方を残しました。
    - 480（大きい顔用）はしきい値 0.85 を使用しました（0.6 では、敷物・スマホ・照明の筋を顔と誤検出しました）。
    - 背景のポスターや写真の顔も検出されるため、「顔の真ん中が人物マスクの中にあるか（0.3 以上）」で本物の人の顔だけに絞ります。
    - 主役は「いちばん大きい顔」としました。
  - **Attention**：しきい値 0.75 で口の位置も取得し、コマごとに `[x, y, w, h, score, mouth_x, mouth_y]` を JSON に保存しました。
- **要るもの**：opencv とモデル。

## 2. 手：MediaPipe HandLandmarker
- **何のため**：文字を手にかぶせない、手の持ち物によるマスクの穴埋め（01）、手がかりの無い人を見つける。
- **しくみ**：`mediapipe.tasks.vision.HandLandmarker`（モデル `hand_landmarker.task`、`num_hands` 6、検出のしきい値 0.3）で 21 点の手のランドマークを取り、外接矩形（箱）を作ります。
- **要るもの**：mediapipe とモデル。

## 3. 体の動き：YOLO11 pose
- **何のため**：**音ハメの固定点**の特定（手が止まる＝キメ、手を打つ＝拍手、を拍に必ず合わせる）、およびダンスの動きの確認。
- **しくみ**：YOLO11 の pose（`imgsz` 960）を使います。画面内で大きい順に人物を選び、左から並べて、1 人ずつ次の値を毎コマ出力します。
  - `up`：手首の高さ（肩の真ん中より上を＋、肩幅で割る）
  - `gap`：両手首の間 ÷ 肩幅
  - `spd`：手首の速さ（px／コマ）
  - `fold`：上体の折れ
  - `h`：箱の高さ
- **読み方**：数値の表から「手首が肩より上で止まる」「両手首が急に近づく（拍手）」コマを読み取り、音ハメの `pins`（`[動画の秒, クリップの頭からの秒]`）に記述します。
  - 例（Attention）：「Stop! の止め」は動画の 5.96 秒、3 連のヒットは 6.58・7.04・7.58 秒、拍手は 6.00 秒。それぞれを曲の指定した拍・言葉に合わせました。
- **要るもの**：ultralytics（重みは初回に自動ダウンロードされます）。GPU があると高速ですが、CPU でも動作します。

## Mittler で使うには
- **ポーズ**：解析の `pose` を使います（`pose.json`：コマごとに、人ごとの箱と 17 点を 0〜1 の座標で出力）。読み取ったキメのコマを、映像クリップの音ハメの「そのほかの設定」の `pins` に書くと、音ハメがそこを必ず通ります（`docs/タイムライン形式.md`）。
- **顔・手**：Mittler に検出の道具はありません。必要な場合は上のしくみを作品の道具として実装し、結果（JSON）を作品の素材に置いてエフェクトから読み込みます。
  - 文字の置き場所を決めるときは、顔・口・手の箱をよける高さをあらかじめ計算しておくと、コマごとに文字が逃げ回るのを防げます。
