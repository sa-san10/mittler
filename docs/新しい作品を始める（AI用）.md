# 新しい作品を始める（AI 用。スキル mittler-new-project が読む手順の正本）

VS Code で空のフォルダを開き、横のエージェント（Claude Code など）に「Mittler で新しいプロジェクトを始めたい」などと言われたら、この手順どおりに空の作品を準備します（以下の `<mittler>` は Mittler の場所を指します）。

人が自分で作る場合は、次のいずれでも同じものが作成されます（中身はいずれも `tools/new_project.js` の `create()` です）。

- 編集画面の上のバーの **「＋ 新規」**（今開いている作品の隣に作成。置く場所・フォルダ名・表示名・大きさ・fps・長さを窓で指定）
- VS Code のコマンド **「Mittler: 新しい作品を作る」**（まだ作品を開いていないとき）

## 1. 置き場所を決める

- **作業フォルダの確認**：いまエージェントを開いているフォルダの中身を `dir` / `ls -A` で確認します。
  - 空、または `.claude/`・`.vscode/`・`desktop.ini`・`Thumbs.db` のみ → **ここに作成します**。
  - ほかのファイルがある → ここには作りません。「この中に新しいフォルダ `<名前>` を作ってそこに作るか、空のフォルダを開き直すか」をユーザーに確認します。既存ファイルを消したり動かしたりしてはいけません。
- **フォルダ名の制約**：**英数字と `-` `_` のみ**（`^[A-Za-z0-9][A-Za-z0-9_-]*$`）にします。日本語や空白は ffmpeg などへの受け渡しで壊れることがあります。
  - いまのフォルダ名が条件に合わない場合は、その中に英数字の名前のフォルダを作ってそこに作るか、名前を変えて開き直すかを確認します。作品の内容から短い英語の名前案（例：`summer-mv`）を提案してください。
- **既定の置き場がある場合**：作品をまとめて置くフォルダ（その PC の決まり。親フォルダの `CLAUDE.md` などに書かれていることがある）があるのに別の場所で始めたときは、そのまま進めて構いませんが一言添えます。

## 2. 決めること（言われていなければ既定で進める。聞きすぎない）

| 項目 | 既定 | 言葉からの決め方 |
|---|---|---|
| 表示名（`--title`） | フォルダの名前 | 作品名・曲名が言われていればそれ（日本語可） |
| 大きさ（`--width --height`、**偶数の整数**） | 1920×1080 | 「縦」「ショート」「TikTok」「リール」「スマホ」→ 1080×1920、「正方形」→ 1080×1080 |
| fps（`--fps`、正の数） | 30 | 素材の動画が 24fps（動画生成の H3 など）で、それを主に使う MV なら 24 |
| 長さ（`--duration` 秒、正の数） | 60 | 曲の長さ・秒数が言われていればそれ（あとで曲を入れたら合わせられる） |

## 3. 作る

`<mittler>` はスキルの手順 1 で見つけた場所です（このファイルの 2 つ上のフォルダ。配布版なら VS Code の拡張の置き場 `sa-san10.mittler-<版>`）。

```
"<mittler>\tools\mittler.cmd" node "<mittler>\tools\new_project.js" "<作品フォルダ>" --title "<表示名>" --width 1920 --height 1080 --fps 30 --duration 60 --lang ja --json
```

### 引数と実行時の注意

- **`--lang` はユーザーと話している言葉に合わせる**：日本語なら `--lang ja`、英語なら `--lang en`（省略時は英語）。最初のトラックやメタデータの段の名前（字幕／Subtitles など）がその言語になります。`AGENTS.md`・`CLAUDE.md`・`README.md` は日本語のままです。
- **`mittler.cmd` の動作**：VS Code の `Code.exe` を Node として使います（Node の別途導入は不要。引数はすべて渡り、終了コードは Node のものが返ります）。「VS Code not found」の場合は、環境に `node` があればそちらを使います（`node "<mittler>\tools\new_project.js" …`）。
- **引数の書式**：`--名前 値` の形式で指定します（`--名前=値` は引用符で囲まないと cmd が `=` で分割してしまいます）。

### 出力 JSON とエラー条件

- **返る JSON（`--json`）**：`dir`・`timeline`・`files`・`git`（`committed` なら最初のコミットまで完了）・`notes`（git の名前が無いなど）。
- **作成が断られるとき**（何も作らずに理由を出力して終了コード 1）：
  - フォルダ名が英数字と `-` `_` でない
  - フォルダに中身がある
  - 幅・高さが偶数の整数でない
  - fps・長さが正の数でない

### 生成されるもの

| パス | 中身 |
|---|---|
| `<名前>.cut.json` | タイムライン（字幕・映像・動画化予定・効果音・音楽のトラック、カット・ト書きのメタデータ） |
| `characters.json`・`pronunciation.json` | キャラ設定・読み辞書（空） |
| `effects/` | エフェクト（字幕・重ね絵・フェード・色の手直し） |
| `assets/` | 素材フォルダ（`images` `videos` `sfx` `bgm` `music` `voice` `fonts` `characters` `overlays`） |
| `work/proxy/`・`output/` | 再生用プロキシ・書き出し先 |
| `AGENTS.md`・`CLAUDE.md`・`README.md`・`.gitignore` | 作品の説明と決まり（`AGENTS.md` はエージェント共通、`CLAUDE.md` は Claude Code の入口で `AGENTS.md` と `.mittler/guide.md` を取り込む） |
| `.claude/settings.json` | 話しかけるたびに編集画面の今を添えるフック（既存の設定は残す） |
| `.mittler/` | その PC 用ファイル（`env.json`＝Mittler の場所、`guide.md`＝AI 用ガイドの写し、中継。git には入れない） |
| `.git/` | git リポジトリ（返る JSON の `git` が `committed` なら最初のコミットまで完了。git の名前が無いときなどは `notes` に理由） |

> 作品のファイルには Mittler の場所（絶対パス）を書きません。Mittler の場所は `.mittler/env.json` の `mittler_dir` に記録され、編集画面で開くたびにその PC 用に書き直されます。

## 4. 作ったあと

1. **作った文書をすぐ読む**：この会話は作品の `AGENTS.md`・`CLAUDE.md` ができる前に始まっているため、**作った `AGENTS.md` と `.mittler/guide.md`（AI 用ガイドの写し）をいま読み込みます**（このあと頼まれる作業のため）。
2. **ユーザーに短く伝える**：
   1. できたもの（フォルダ・表示名・大きさ・fps・長さ）。変えたければ言ってもらえば直すこと（編集画面の上のバーの長さ・大きさのボタンでも変更可能）。
   2. 開き方：左のエクスプローラーで `<名前>.cut.json` をクリックすると編集画面が開くこと（開かなければ右クリック →「ファイルを開くアプリの選択」→ Mittler タイムライン）。
   3. 次にやること：素材を `assets/` に入れる（曲は `assets/bgm/`）、キャラは編集画面の「キャラ」タブで作る、拍（ビート）は「曲の拍を調べて入れて」と頼む（解析が入っている PC で）、書き出しは上のバーの「書き出し」。
   4. 次にエージェントを開き直すと、作品の決まり（`CLAUDE.md` → `AGENTS.md` と `.mittler/guide.md`）を自動で読み込むこと（どちらも作品の中なので、読み込みの許可は聞かれない）。

### やらないこと

- 頼まれていない素材を入れない。
- GitHub などに上げない（頼まれたときだけ）。
- 中身のあるフォルダに作らない・既存ファイルを消さない。
