# 01 人物のマスク（人を切り抜く）

**何のため**：文字やステッカーを人の後ろに回す（床に貼った字の手前を人が通る、歌詞が人の後ろから出る）、人だけに光を当てる・色を変える、背景だけ揺らす、といった表現に使います。
Mittler では、マスクを作品の素材（動画、またはコマごとの 8bit PNG）として配置し、エフェクトから読み込みます。

## 1. U²-Net（u2net_human_seg）— 速い・まあまあ
- **使った作品**：偽マリア（最初の版）、Attention（すべてのコマ）。
- **しくみ**：rembg の人物用モデル `u2net_human_seg.onnx` を、onnxruntime の CPU で 1 コマずつ処理します（1 コマあたり 0.1〜0.2 秒）。rembg を使わず、onnxruntime で同じ前処理を書いても同じ結果になります。
- **弱いところ**：
  - 髪のふちや、手に持った物（マイク・手帳など）が抜けやすい。
  - 背景の人物っぽい物（ポスター・煙など）が誤って入る。
  - コマごとにちらつく。
- **工夫**：
  - 前のコマと混ぜてちらつきを抑え、ふちを少しぼかす。
  - 動画は BT.709 で RGB として読み込む（色タグが無い素材でも同じ色にするため）。
- **要るもの**：onnxruntime・opencv・pillow・numpy、およびモデル。

## 2. SAM 2.1 — きれい・人ごとに分かれる（GPU）
- **使った作品**：偽マリア（仕上げの版）。
- **しくみ**：
  - SAM 2.1 hiera-large の**動画の予測**（`SAM2VideoPredictor`）にカットの全コマを入れ、人を 1 人ずつ追跡します（bfloat16、1024 に縮小して渡し、960×540 で出力）。
  - 「どこに人がいるか」の手がかりは、顔（YuNet）と手（MediaPipe）の点から自動生成します（02）。6 コマおきに見直し、新しく出てきた人を追加したり、外れかけた人を補正したりします。
  - 手がかりをそのまま渡すと肌だけ・顔だけになることがあるため、そのコマで**画像の予測**を何通りか実行し、「顔を含む・ほかの人の顔を含まない・U²-Net の塊から大きく外れない」候補の中から最大のもの（体全体）を渡します。
  - 人ごとの確率を合わせ、元の絵をガイドにしたガイドフィルタで髪のふちに寄せます。人ごとの ID マップも出力します。
- **穴埋め**：マイクや手帳など、手に持った物の箇所に穴があくことがあります。1 人に囲まれて手が触れている穴と、手から出ている持ち物を、U²-Net・SAM 2 の画像予測・前後 ±2 コマの多数決で補います。
- **要るもの**：torch（CUDA）・SAM 2、およびモデル `sam2.1_hiera_large.pt`。MV 1 本の全カットで数十分かかります。

## 3. YOLO-seg ＋ U²-Net — 「この 1 人だけ」のマスク
- **使った作品**：Attention（前に出てきたソロの人だけを切り抜き、その人の後ろから字を出す）。
- **しくみ**：YuNet の結果から「顔の高さが 185px 以上の人」をソロと判定します。YOLO11 の seg による人物マスクのうち、その顔を含むものを選び、ふちを U²-Net のマスクで整えます。
- **要るもの**：ultralytics（重みは初回に自動ダウンロードされます）。

## Mittler で使うには
- **作る**：解析の `mask`（YOLO11 seg。動画は白＝人の `mask.mp4`、画像は `mask.png`）と `cutout`（rembg の `u2net_human_seg`。画像のみ、透明つき）を使います。
  - クリップを右クリック →「解析」、または `python .mittler/api.py . analyze <クリップ> mask` で実行します。
- **読む**：マスクを作品の素材に配置し、エフェクトから読み込みます。人のマスクが必要なエフェクトには `needs: ['matte']` と書き、人のマスクのトラックより上に配置します（`docs/エフェクトの書き方.md`）。
- **SAM 2 を使う場合**：SAM 2 の人ごとのマスクと穴埋めは Mittler にありません。必要な場合は、上のしくみを作品の道具として実装し、結果を素材に配置します。
- **作り直すときの注意**：
  - 古い結果を消さず、名前を変えて残します（前の版に戻れるようにするため）。
  - マスクを作り直したら、キャッシュ済みのフレームを破棄します（`api frame-cache clear`）。
