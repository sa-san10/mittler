# Mittler で MV を作る

手順の正本は Mittler の中の説明書です（手順を変えるときは説明書を直します）。

1. Mittler の場所 `<mittler>` を探します。作品の中なら `.mittler/env.json` に書いてあります。無ければスキル `mittler-new-project` と同じ順（環境変数 `MITTLER_DIR` → このスキルのフォルダの `mittler_dir.txt` → VS Code に入っている Mittler の拡張のフォルダ）で探し、見つからなければユーザーに聞きます。
2. `<mittler>\docs\MVを作る（AI用）.md` を読み、そのとおりに進めます。作品がまだ無ければ、先に `<mittler>\docs\新しい作品を始める（AI用）.md` で作ります。
3. 返事はユーザーの言葉で、短く書きます。
