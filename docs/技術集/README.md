# 技術集：Mittler より前の作品で使った技術

Mittler を作る前から、作者が AI エージェントと制作してきた動画（MV・ダンス動画・紙芝居）で実際に使った技術をまとめています。
各文書は、**何のために・どういうしくみで・何が要るか・Mittler でいまどこまでできるか** の順に整理しています。
新しい作品で同じ表現を行う際の手がかりにしてください（Mittler に部品が入っているものは、そちらを使います）。

> **読み方**
> - 数値（しきい値・倍率・秒数など）は、作者の作品で効いた値の例です。曲や素材が変われば測り直してください。
> - 「Mittler に無い」と書いてある道具は、このリポジトリには入っていません。同じことを行う場合は、しくみの説明をもとに作品側（作品の `tools/` や `effects/`）に書いてください。
> - 例に出てくる作品：偽マリア（MV）・Attention（ダンス動画）・False Maria（リリック動画）・紙芝居の作品。いずれも作者が AI で作ったものです。

## 決まり（使う前に）
- **新しいパッケージやモデルを入れる前に、必ずユーザーに確認する**（モデルのダウンロードも外部通信を伴うため同様です）。
  - インストール先は作品ごとに分けず、用途ごとの Python 環境（venv）にします。
- 重い解析（GPU を使う処理・長い動画の解析）は、GPU のある PC で実行します。
- 解析結果（マスク・顔の点・拍・単語の時刻など）は**作品の素材として保存し、Mittler からそれを読む**形にします（描画のたびに解析しないため、どのコマからでも同じ絵になります）。
- 素材は上書きしません。作り直すときは新しい名前で保存します。

## 解析の AI の環境（例）

Mittler の解析は、クリップを右クリック →「解析」、または `python .mittler/api.py . analyze <クリップ> <種類>` で実行できます（中身は `pyengine/mittler/analyze.py`）。
これらは解析用の Python 環境で動きます。作者の PC では、次のパッケージを 1 つの venv（Python 3.12）にまとめています（一覧は `setup/requirements-av-ai.txt`、動作確認は `tools/av_ai_check.py`）。

| 入れるもの | 使い道（解析の種類） |
|---|---|
| torch（CUDA）・torchaudio | 下のすべての土台。torchaudio の MMS_FA は強制アラインメント（04） |
| ultralytics（YOLO11 pose・seg） | `pose`・`mask` |
| rembg（u2net_human_seg） | `cutout` |
| demucs | `stems` |
| faster-whisper（large-v3） | `transcribe` |
| librosa・soundfile | `beats` |

このほか、作品ごとの道具で使ったパッケージは次のとおりです。
- `onnxruntime`（U²-Net を直接回す）
- `opencv-contrib`（YuNet・SIFT・LSD）
- `mediapipe`（手）
- SAM 2（人ごとのマスク）

### 使うときの注意（作者の PC で分かったこと）
- **モデルの置き場**：環境変数 `AV_AI_MODELS`（未設定ならホームディレクトリ配下）を使います。`tools/av_ai_check.py` と同じ場所にしておくと、再ダウンロードを防げます。
- **faster-whisper**：
  - PyAV は 15 に固定します（16 以降は faster-whisper の読み込みが通りません）。
  - GPU で動かすには CUDA 12 の cuBLAS・cuDNN が必要です。`setup/av_ai_cuda12_path.pth` が起動時に PATH へ追加します。
- **torchaudio 2.11**：`torchaudio.load` に torchcodec が必要なため、音声は soundfile で読み込みます。
- **Windows の「スマート アプリ コントロール」**：オンになっている PC では、初めて読み込む DLL がときどきブロックされます。もう一度実行すると通ることが多く、また古い版の torch は読み込めない場合があります。
