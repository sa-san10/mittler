# 12 確かめ方（シート・画素の比べ・別の AI に見せる）

## 1. 確認シート（コンタクトシート）
- 指定時刻のコマを並べた 1 枚の画像を作り、自分またはユーザーが目視確認します。
  - 修正後は、**［直す前｜直した後｜差を 8 倍］**の 3 つを横に並べると変更点が一目で分かります。
- 文字・手・指は**拡大して**確認します（手の指の本数を数える。縮小したシートでは見逃しやすいため）。
- **Mittler のコマンド**：次のコマンドで静止画を出力できます。
  ```
  python -X utf8 -B -m mittler stills <タイムライン> --at <秒> --out <フォルダ>
  ```

## 2. 画素・ファイルで比べる
- **同一性の検証**：静止画の SHA-256 で比較します。エンジンを修正したら、同じ作品・同じ時刻の静止画が修正前とバイト単位で一致することを確かめます。
- **近似度の検証**：
  - 映像：ffmpeg の `psnr` フィルタ（全コマ）。
  - 音声：PCM に変換して、差・相関・ずれ（相互相関）を計測します。
- **通し書き出しの一致**：同じ ffmpeg・同じ区間分割なら MP4 がファイル単位で一致します（ffmpeg のバージョンが違うと絵が同じでもファイルは一致しません）。
- **揺れの検証**：演出なしの版と位相相関で揺れの量を比較します。また、揺らした画面に黒い縁が出ていないかを全コマで数えます。
- **欠損ファイルの確認**：素材を整理したあとは全体を粗く（1 秒おきなど）描画し、警告や例外が出ないことを確かめます。

## 3. 別の AI に見せる
- 書き出した動画や曲を、動画・音を扱える別の AI に見せて気づきを出させます（作者は Gemini のコマンドラインツールを使用）。
- **依頼時に必ず書く制約**：
  - 「スクリプト・シェル・インストールは一切しない。指定したファイルを見るだけ」
  - 「指定したファイルと出力先のほかに触らない」
  - 「開けなければ、開けなかったとだけ書く。推測で答えない」
  - 結果は、あらかじめ決めた場所のファイルに書かせます。
- **音声のみを渡すコツ**：音だけを聞かせるときは、黒い画面の動画にして渡すと通りやすくなります。
- **使い道と注意**：曲の構成・雰囲気の把握、書き出し動画の見直し、効果音の案出しに有効です。ただし**時刻は粗い**ため、正確な時刻は聞き取り（04）と拍（03）を正とします。

## 4. Mittler の動作確認
- `tools/smoke_*.py` を実行します（ヘッドレス、localhost のみ。一覧は `docs/スターターガイド（AI用）.md` の 7）。
- ユーザーが開いている本番のタイムラインでは流しません（写し `<名前>.test.cut.json` か、試しの作品で実行します）。
- 自分で起動したサーバーは、終わったら必ず停止し、停止したことを確認します。
