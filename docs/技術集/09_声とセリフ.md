# 09 声（TTS）・セリフの聞き取り・音量そろえ

Mittler には TTS トラックがあり、Gemini TTS・VOICEVOX、キャラごとの声、テイク管理、作品ごとの読み辞書 `pronunciation.json` を使えます（道具は `tools/tts_gen.py`・`tools/gen/gemini_tts.py`）。
演技タグの書き方は `docs/GeminiTTSの演技タグ.md` を参照してください。ここでは、紙芝居や解説動画の制作で分かった知見をまとめます。

## Gemini TTS
- **鍵**：Windows の資格情報マネージャー（`ps:GEMINI_API_KEY`。環境変数が優先）を使います。値は表示せず、ファイルにも書きません。
- **基本の声の固定**：キャラの基本の声（声の名前と声の説明文）は、キャラ設定に決めた文のまま使います。カットごとに言い換えると声質が変わってしまうため、演技の変化は演技タグで足します。
- **文字数と会話**：会話は 2 人まで 1 回で生成できます。1 回の文字数は控えめ（タグ込みで 6000 字くらいまで）にします。長いセリフを黙って分割したり言い換えたりしません。
- **声を作り込む例（低く甘い声）**：基本の声の説明に「低めで甘く響く、色気のある声…」のような文を足し、生成した音声を `ffmpeg -af atempo=1.15` で少し速くします（ピッチはそのまま）。ゆっくり話す声は速度を上げると聞きやすくなります。
- **音量バランス**：ミックスではセリフごとに LUFS をそろえます（例：低い声 −19、ゆっくり話す人 −17）。RMS でそろえると声質によって大きさが違って聞こえました。
- **読み辞書**：ユーザーが単語と読みを指定したときだけ、作品の `pronunciation.json` に追加します。

## VOICEVOX
- その PC で動いている VOICEVOX（`http://127.0.0.1:50021`）を使います。話者の一覧は `/speakers` で取得できます。
- Mittler では、話者・速さ・高さ・抑揚・音量・前後の無音を設定できます。

## セリフの聞き取り（ASR）と区切り
- **聞き取り**：`faster-whisper`（小さいモデルで足りる。オフライン）で単語の時刻つきで取得します。**結果は下書きの根拠であり、自動で確定せず**人が確認して修正します。
- **連続ナレーションの切り出し**：見直した境目で、**劣化なしに PCM で切ります**（−45 dBFS の無音を探し、前後に 0.04 秒の余白を付ける）。
- **場面の間**：セリフを切らずに場面の無音を差し込みます（元の音はそのまま残し、時刻と音を別に記録）。
- **紙芝居の制作フロー**：台本 → 絵 → TTS → 聞き取り → 時刻の確認 → 描画 → 音量そろえ。

## 音量そろえ（loudnorm の 2 パス）
- ffmpeg の `loudnorm` を 2 パス（1 回目で測定、2 回目で適用）でかけます。
  - 目標値：**−16 LUFS・トゥルーピーク −2・LRA 11**
  - モード：`linear` を指定し、ピークの都合で無理な場合は `dynamic` にします。
  - 保存：入力（元の WAV・そろえる前の動画）は残し、映像ストリームはコピーします。
- 完成した動画は渡す前に必ず音量をそろえます。
- **Mittler での対応**：書き出し設定 `settings.export.loudnorm` で、書き出しの最後に同じ 2 パスを適用できます（`docs/タイムライン形式.md`）。

## 効果音
- ライセンスが動画に合う素材を使い、使う前に配布ページでライセンスを確かめます。
- 素材ごとにピークを 1 にそろえてから、dB とフェードをかけて混ぜます。
- 効果音の案（どこに何の音を入れるか）は、書き出した動画を別の AI に見せて出させることもできます（12）。時刻は粗いため、配置時刻は自分で決めます。
