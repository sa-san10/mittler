# エフェクトの書き方（Python エンジン、After Effects のエクスプレッション相当）

エフェクトは、プロジェクトの `effects/<名前>.py`（コード）と、タイムラインのクリップ（いつ・どのカットに・どのパラメータでかけるか）の組で構成されます。

- Claude Code も人も、新しいファイルを書けばエフェクトを追加できます。
- 編集画面の「コードを開く」から現在のコードを開いて修正できます（保存すると自動で描き直されます）。

## 形

```python
"""何をするエフェクトか（編集画面の「説明」に出る。経緯・ユーザーの指示もここに書く）"""
import numpy as np

STAGE = 'v7'   # 'v7'＝float32 の絵（0〜255、曲の終わりまで）／'post'＝uint8 の絵（最後の段：前のリリック・シャッター・暗転）／'scene'＝場面の絵（下）
DOC_EN = """Clones of the person..."""            # 任意：英語の画面の「説明」（無ければ上の日本語の説明を出す）
META = {
    'label': '分身',                               # タイムラインに出る名前
    'label_en': 'Clones',                          # 任意：英語の画面の名前（無ければ label。'label': {'ja': '分身', 'en': 'Clones'} と書いてもよい）
    'window': {'start': 't', 'dur': 'dur'},       # クリップの長さとパラメータの対応（下）
    'time_params': ['t'],                          # クリップを動かしたらいっしょにずらす、曲の時刻のパラメータ
    'needs': ['matte'],                            # 人のマスクが要る（人のマスクのトラックより上に置く）
    'params': {'n': {'type': 'int', 'min': 1, 'max': 6}, 'alpha': {'type': 'number', 'min': 0, 'max': 1.5, 'step': 0.01}},
}


def apply(ctx, f, clip):
    p = clip.get('params', {})
    ...
    return f      # 新しい絵を返す（f を書き換えてもよい）
```

### `META` の任意キー一覧

| キー | 意味 |
|---|---|
| `params` の `type` | 編集画面の右欄の入力形式：`number`・`int`（`min`・`max`・`step`）、`bool`、`text`、`choice`（`choices`）、`color`（`[r, g, b]`）、`lines`（`["…", …]`。1 行に 1 つのテキスト欄）、`font`（`root` からの相対の書体。アセットの書体から選ぶ）、`json`（そのほか。JSON の欄） |
| `'draft': True` | `ctx.draft` に対応済みの印（任意。下の「ドラフト品質」） |
| `'scale_aware': True` | `ctx.scale` に対応済みの宣言（マスター書き出しは、これの無いエフェクトがあると名指しで止まる。下の「マスター書き出し」） |
| `'uses_fi': True` | `ctx.fi`・`ctx.sfi`（コマ番号）で絵が変わる注記（60fps で番号の進みが変わる。マスター書き出し時に注意として表示） |
| `'gl3d': True` / `'blender': True` | GPU の 3D・Blender で描く印（編集画面に「3D」の印を出す。`'blender'` はクリップ欄の「描き直す」なども表示。下の「3D のエフェクト」） |
| `'defaults'`・`'dur'` | 編集画面のアセット窓で「この時刻に置く」ときの既定値（`{パラメータ: 値}`）と長さ（秒）。無ければ従来どおり `min`・`choices` の頭・2 秒 |

### 画面の言葉（英語・日本語対応、2026-11-13〜）

- 名前は `'label'`（日本語）＋ `'label_en'`（英語）、または `'label': {'ja': …, 'en': …}` と書きます。説明は冒頭の説明文＋ `DOC_EN` です。
- いずれも任意で、前からのエフェクト（`label` だけ・説明は日本語だけ）もそのまま動きます（英語の画面でも、書かれている言葉で表示します）。描画する絵には影響しません。
- `label_en` があるのは `effects_lib/common`（字幕・重ね絵・フェード・色の手直し）・`effects_lib/beatfx`・`effects_lib/false_maria`、`DOC_EN` があるのは `common` と `false_maria` です。
- パラメータ名（`params` の鍵）は言語で変わりません。

|---|---|
| `ctx.t` | 曲の時刻（コマにそろっている） |
| `ctx.fi` / `ctx.sfi` | 曲のコマ番号 / 動画（とマスク）のコマ番号（カットインのコマ止めでずれる） |

| `ctx.W` `ctx.H` `ctx.fps` | 画面の大きさ・コマ数/秒 |
| `ctx.m` / `ctx.m_s` | 人のマスク（`W×H` と `960×540`、0〜1。無ければ `None`）。背景ビートで動いたあとの形 |
| `ctx.beats` | 拍（`pulse(t, decay)`・`hits(t0, t1)`・`t`（時刻の並び）・`b`（`[時刻, 小節の頭, 強さ]`）） |
| `ctx.level()` | 区間の強さ（0〜1） |
| `ctx.settings` | タイムラインの `settings`（`tonemap`・`sticker_global`・`matte_dir`…） |

| `ctx.root` | 素材の根（プロジェクトの `base/`） |
| `ctx.clips_of('illust')` | 指定名のエフェクトのクリップ一覧（ほかのクリップを見て決める処理向け） |
| `ctx.cam` | そのコマのカメラ `{zoom, dx, dy, rot}`（下の `camera()`。床に貼る字をカメラに合わせて動かすなど）。ほかのコマのカメラは `ctx.eng.camera_at(t)` |
| `ctx.view` | 画像クリップの切り取り `{x0, y0, cw, ch, sw, sh, scale, base}`（画像の上の位置 `(x, y)` は画面の `((x / base − x0) × scale, (y / base − y0) × scale)`。`'scene'` 段で画像に貼りつく物に） |
| `ctx.eng.scene_frame(t, カット)` | そのカット（場面）の絵（float32。映像クリップ＋`'scene'` 段）。場面の切り替え（前と次の場面を混ぜる）に使う |
| `ctx.draft` | ドラフト品質で描いてよいか（`bool`）。読まなければ今まで通り。ドラフトでも時刻だけで絵が決まること・前のコマを覚えないことは守る（下の「ドラフト品質」） |
| `ctx.scale` | キャンバスの倍率（いつもは `1`、マスター書き出しは `2`。整数なら `int`）。`ctx.W`・`ctx.H` はもう掛けたあとの大きさ。px の値に掛ける（下の「マスター書き出し（ctx.scale）」） |

### 共通部品と作品専用部品

- **共通の部品**：
  - `from mittler.helpers import smooth, ease_out_back, paste_piece, draw_sprite, face_box, load_matte, grid, Beats, draft_n`
  - `from mittler.lib import look`（光・トーンマップ・スクリーン合成）
- **素材の根**：`ctx.root`（環境変数なら `MITTLER_ROOT`）。
- **作品だけで使う部品**：作品の `effects/_lib/` に置き、エフェクトの冒頭で `sys.path` に足して読み込みます（Attention・偽マリアMV の字のシールと同じ形）。
- **自動再読み込み**：部品（`_lib` の `.py` や import したほかのエフェクト）を直すと、動いている描画サーバーも次のコマから自動で読み直します（2026-11-16〜。前は最初に読んだ版が残ったため必要だった、自前の再読み込みの仕掛けは不要です）。
- 作品の `effects/` に `__pycache__` は書きません。

## カメラ（camera()）

エフェクトに `camera(ctx, cam, clip)` があると、エンジンは絵を描く前にそのコマにかかっているクリップを処理順に通し、そのコマのカメラ `{zoom, dx, dy, rot}`（`rot` は度）を決めます（`ctx.cam`）。

- `"sample": "source"` の映像クリップでは、素材の拡大とこのカメラを 1 回の補間でかけます（あとから拡大するよりぼけません）。
- 戻り値は新しい `cam` の dict です（`None` ならそのまま）。


## 場面の段（STAGE 'scene'、2026-10-21、紙芝居の作品で足した）

紙芝居のように「場面（カット）ごとの絵に付いている物」（フキダシ・描き文字・キラキラ・集中線・その場面だけのノイズ）は `STAGE = 'scene'` にします。

- エンジンは映像クリップの絵にそのカットの `'scene'` 段クリップを重ねたものを「場面の絵」にし（`'v7'` より先）、場面切り替えエフェクトは `ctx.eng.scene_frame(t, カット)` で前と次の場面の絵をそれぞれ描いて混ぜます（切り替え途中もフキダシ・揺れが付いたままになります）。
- クリップの頭（終わり）が場面の映像クリップの頭（終わり）と同じなら、場面が映っているかぎり（前後の切り替え途中も）かかります。


- 画像クリップ（紙芝居のコマ）もカメラ（`camera()`）を受けます：`zoom` を寄りにかけ、`dx`・`dy`（画面の px）だけ切り取りをずらし、ずれているあいだは `zoom_min` より寄ります（揺れでふちが見えないようにするため）。クリップの `follow_cam: false`（タイトルカード）は受けません。

## 決まり

- **絵は時刻・コマ番号・マスクだけで決める**：前のコマを覚えないこと（並列書き出しで区間に分けても、どこから描いても同じ絵になるようにするため）。
  - 乱数は `np.random.default_rng(決まった種)` を使います。`hash(文字列)` はプロセスごとに変わるため使えません。
  - `ctx.draft` で分けたドラフトの描き方の中でも同じです（固定種の乱数・前のコマを覚えない。ドラフトの書き出しも区間に分けて並列に描きます）。
- **重ね順＝処理の順**：タイムラインの下のトラックから順にかかります。下のものの上にかかる調整（色・光）も、上に描く物（スタンプ・字）も同じです。
- **カット限定**：クリップに `cut` があれば、そのカットを映しているあいだだけかかります。
- **速さ**：1 コマ数秒以内を目安にします（プレビューは止めたコマを描画サーバーで描きます）。重い下ごしらえは `ctx.cache` に入れます。
- **ためた絵（フレームキャッシュ、2026-11-16、`pyengine/mittler/fcache.py`）**：
  - 描いたコマは作品の `work/cache/frames/`（PC の設定 `mittler.cache.dir` があればその下。インストールガイドの 12）にため、そのコマの鍵が同じなら描かずに出します。
  - **書き出しも、ためた絵（劣化なしの PNG）を描かずに使います**（差分書き出し）。鍵に入らないものを読むエフェクトは古い絵のまま書き出されるため、以下の宣言を必ず書いてください。
  - 自動で鍵に入るもの：そのコマの前後 2 秒にかかるクリップ・かかっているエフェクトのコード（import する作品のエフェクトと `effects/` 配下のフォルダ全部）・`clips_of('名前')` で読む名前のクリップ全部・`settings`・`meta` など。
  - **遠くのクリップや別ファイルを読むエフェクトの宣言**（ファイル冒頭に記述）：
    - `CACHE_READS = ['名前', …]`：指定エフェクトのクリップ全部を読む
    - `CACHE = 'all'`：映像に効くクリップ全部を読む（どこを直しても、このエフェクトがかかるコマは描き直す）
  - クリップの `params` に書いていないファイル（決まった場所の解析結果など）を読み直したいときは、`python .mittler/api.py . frame-cache clear` で全部捨てます。

## ドラフト品質（ctx.draft、2026-10-30）

重いエフェクトは、**任意で**「ドラフト用の軽い描き方」を持てます。`ctx.draft` が `True` のときだけ軽く描き、`False`（いつも）は今までの描き方のままにします。`ctx.draft` を読まないエフェクトは、ドラフトでもマスター品質で描きます（対応しなくて構いません）。

```python
from mittler.helpers import draft_n

def apply(ctx, f, clip):
    n = draft_n(ctx, 6)          # ドラフトは分身を 1/3 に（6 → 2）。直接 `2 if ctx.draft else 6` と書いてもよい
    ...
```

- **軽くする定石**：
  1. 粒・コピー・残像の段数を減らす（`draft_n`）
  2. ぼかし・グローのパスを省くか半径を縮める（ガウシアンが大抵の犯人）
  3. 補間を落とす（BICUBIC → BILINEAR / NEAREST）
- **ドラフトでない絵は 1 ビットも変えない**：分けるのは `if ctx.draft:` の中だけにし、従来の計算順・型・乱数の引き方を変えません。直したら、直す前と静止画の SHA を比べます（スターターガイド（AI用）の 5）。
- **ドラフトになる条件**：書き出しの「ドラフト」（`mittler video … --draft`。静止画は `mittler stills … --draft` のときだけ）と、描画サーバーの `/frame?…&draft=1`（編集画面のサーバーの `/api/frame` も渡す。編集画面はまだ付けない）。PNG で保存と本番の書き出しは常にドラフトではありません。
- **対応印**：対応したら `META` に `'draft': True` を書いて構いません（「ドラフト対応済み」の印。動作には不要ですが `/effects` にそのまま出るため編集画面のバッジ等に使えます）。
- **優先順位の調べ方**：重い順は `/frame?t=<秒>&prof=1`（スターターガイド（AI用）の 6）で計測し、上位 2〜3 本から対応します。
- 対応済み：`effects_lib/false_maria/fm_light.py`（光とトーンマップ）。
- 対応済み（2026-10-31）：`effects_lib/beatfx/` の分身ホログラム（ふちの光を省く）・リムライト（芯のぼかしを省く）・ラジアル（残像を 1 枚）・アナモルフィック（丸いぼかしを省く）。

## ビート演出（effects_lib/beatfx、2026-10-31）

作者のダンス動画（Attention）の OVERDRIVE 版の画面演出を、作品をまたいで使える部品にしたものです。名前は演出の語彙（`rim`・`radial`・`anamorph`・`vignette`・`dutch`・`shockwave`・`env`）と揃えています。

いずれも打点の時計（`_lib/beatfx.py` の `Clock`）を使います。設定はタイムラインの `settings.beatfx`（`song_t0`・`beats`・`beat_shift`・`hits`・`extra`・`bar_phase`・`main_end`・`mute`・`decay`・`hit_boost`・`bar_boost`・`faces`。無ければタイムラインの拍のメタデータ）を読みます。

| エフェクト | すること | 置く場所 |
|---|---|---|
| `bfx_grade_keys` | 区間ごとの色（`cool`・`hot`・`mono`・`punch` と、ふだんの打点で上がる彩度） | 映像のすぐ上 |
| `bfx_holo_clones` | 人のマスクの分身ホログラム（区間ごとの分身の並び・打点のウィング） | 人のマスクより上 |
| `bfx_rim` | ネオン・リムライト（人の輪郭が打点で光る。拍ごとに 2 色の組を入れ替え） | 人のマスクより上 |
| `bfx_beat_camera` | ビートのカメラ：横揺れ・ダッチ・縦バウンス・区間ごとの寄り・顔へのゆるい追従・色ずれ（ふちが出ない安全ズーム） | 絵の演出のあと |
| `bfx_radial` | ラジアル・ズームブラー（強いヒットと字のフラッシュ） | カメラより上 |
| `bfx_anamorph` | アナモルフィック・ブルーム（明るいところが横に滲む） | ラジアルより上 |
| `bfx_vignette` | ビネット | ブルームより上 |
| `bfx_star_burst` | 星のビート・バースト（顔のまわりに拍ごとに 6 個） | 字の合成より下 |
| `bfx_text_shockwave` | 文字のショックウェーブ（Attention の前の字の層に効く） | 星のビート・バーストより上・字の合成より下 |

- 星と文字のショックウェーブは、Attention の字の層（`ctx.attn_layers`）があればそこに描きます（字といっしょに合成・粒）。字の層の無い作品では、星は絵に直接重ね、ショックウェーブは何もしません。
- 色の値は作品ごとにユーザーが決めます（既定値は OVERDRIVE 版のものです）。

## 偽マリアのエフェクト集（effects_lib/false_maria、2026-11-13）

偽マリアMV のエフェクト（作者の作品を取り込んだときの部品 21 本）のうち、**コードだけで描くもの**（作品の素材・画像・人のマスク・顔の検出結果を読まず、時刻・パラメータ・下の絵だけで描けるもの）を誰でも使える部品にしたものです（プリセットとして拡張に含めます。画像などの素材が要るものは入れません）。

配布版にも含まれ、編集画面の「エフェクト」タブ →「部品の置き場」の見出し「偽マリアのエフェクト集」から「作品に入れる」で使います。名前は作品の独自エフェクトと重ならないよう `fm_` で始めます。

| エフェクト | すること | 元（偽マリアMV のエフェクト）からの違い |
|---|---|---|
| `fm_light`（光とトーンマップ） | リニアで明るい所を伸ばす → キラ・ラメ → ブルーム → Hable のトーンマップ → 全体の彩度 | 顔の検出結果（`work/fx/survey`）を読まない・ラメの種をプロセスによらない値（カット名の CRC32）に変更・露出などを `params` でも指定可 |
| `fm_edge_neon`（外周ネオン） | 打ちのたびに画面の外周がネオンで光る（人のマスクがあれば背景だけ） | `hits` が空ならクリップの中の拍（拍が無ければクリップの頭）・`colors`・`gain` |
| `fm_shutter_flash`（シャッターの白フラッシュ） | プリ機のシャッターのような白い光 | `times` が空ならクリップの頭の 1 回・作品のカットイン（`illust`）を見ない |
| `fm_match`（ガンマと彩度） | 明るさのガンマと彩度 | 名前と既定値だけ（式は同じ） |
| `fm_tail_credits`（暗転とクレジット） | 黒へフェード → 字間を空けた細い欧文のクレジット | クリップの頭を `song_end` に（動かすとついていく）・クレジットの既定を一般的な 1 行に |
| `fm_hearts`（ハート） | 光るハートが下から上へ大量に飛ぶ（加算の光。ハートの形はコードで描く） | 人のマスクが無ければ画面全体に重ねる（あれば元のとおり人の後ろ）・湧く元 `source`（`bottom` 画面の下＝元のとおり／`point` `x`・`y` の位置から `spread` の幅で／`full` 画面のあちこち）・`t`・`dur` が無ければクリップの頭と長さ（人のマスクが無くても使える） |

- 同じ `params` なら元と同じ絵になること（変えていない所）を、素材の無い試しの作品で確認済みです（静止画の SHA が一致。`fm_hearts` は `bottom`・人のマスクありで元と一致）。
- **入れなかったもの（画像・人のマスクが要る）**：
  - 人のマスクが要るもの：背景ビート・背景グリッチ・背景の差し替え・分身・後光・人の白フチ・シルエット・スプレー・人のマスク（`matte`）
  - 画像が要るもの：ちび・スタンプ・カットイン・下敷きの絵・ワイプ
  - その他：白フラッシュ（カットインのクリップを見て光る）


## マスター書き出し（ctx.scale、2026-10-30、機能追加案03 v2）

マスター書き出し（`python -m mittler master`）は、FHD の作品を **4K のキャンバス（`W×2`・`H×2`）かつ 60fps で**描いて、最後に FHD へ縮小します。

- エフェクトも 4K で描くため、細かい粒（星のきらめきなど）が縮小後も緻密に残ります。
- 60fps はコマ補間ではなく、その時刻の絵をそのまま描きます（絵は時刻だけで決まるため、点滅もコマごとにパキッと瞬きます）。
- 映像素材だけは、先にアップスケール（Real-ESRGAN）と補間（RIFE）をかけたものに読み替えます。

### オプトイン宣言と基本の書き方

- **宣言して使う（オプトイン）**：`META` に `'scale_aware': True` を書きます。マスター書き出しは、作品で使われている（`disabled` でない）エフェクトのうち、これの無いものを名指しで一覧にして描き始める前に止まります（4K で位置のずれた絵を黙って出さないため）。`--force`（編集画面の「scale 未対応のエフェクトがあっても書き出す」）で承知のうえ出力できます。
- **書き方**：px の値（大きさ・太さ・ずらす量・ぼかし半径）に `ctx.scale` を掛けます。面に散らばる物の数（星の数など）は `ctx.scale ** 2` で増やすと見た目の密度が同じになります。

```python
def apply(ctx, f, clip):
    p = clip.get('params', {})
    size = p.get('size', 24) * ctx.scale            # px の値は scale を掛ける
    n = int(p.get('n', 200) * ctx.scale ** 2)       # 面の密度（星の数）は s² で
    ...
```

- 正規化座標（`ctx.W`・`ctx.H` に対する割合）と固定種の乱数で並べる物は、ほぼこの 2 行で対応できます。px の `params` が無いエフェクト（`ctx.W`・`ctx.H` の比率だけで描く・画素ごとの色計算だけ）は、確認して宣言するだけで足ります（`effects_lib/common/fade.py`）。
- **いつもの絵（`scale 1`）は 1 ビットも変えない**：通常の `ctx.scale` は `int` の `1` なので、`x * ctx.scale` は値も型も変わりません。`int(...)` や `max(3 * s, …)` のように掛けたあとの型が変わらないよう書き、`if ctx.scale != 1:` の分岐は最小限にとどめます。直したら、直す前と静止画の SHA を比べます。

### エンジンが `s` 倍にするもの・しないもの

- **エンジンが `s` 倍にして渡すもの（エフェクト側は何もしない）**：
  - `ctx.W`・`ctx.H`
  - 人のマスク（`load_matte` の `ctx.m_s` は `960×540` の `s` 倍、`ctx.m` はそれを `ctx.W×ctx.H` に拡大）
  - 顔の箱（`face_box`）
  - 画像クリップの切り取り（`ctx.view` の `scale`・`base` はキャンバスサイズで決まる）
  - ASS の字幕（libass がタイムラインの大きさから拡大）
- **エンジンが `s` 倍にしないもの（エフェクト側で対応する）**：
  - `params` に書いた px
  - `ctx.cam` の `dx`・`dy`（`camera()` を持つエフェクトが決める。対応するならそこで掛ける）
  - `draw_sprite`・`outline`・`paste_piece` の中の固定 px（落ち影のずれ・ぼかし。呼ぶエフェクトが渡す値で合わせる）

### 60fps のときの扱い

- `ctx.fps` は `60`、`ctx.fi`・`ctx.sfi` は 60fps のコマ番号（進みが 2.5 倍）になります。`ctx.t` と拍（`ctx.beats`）は秒なので変わりません。
- マスクと顔の点はタイムラインの fps で並んでいるため、`load_matte`・`face_box` には従来どおり `ctx.sfi` を渡せばエンジンが直して読み込みます。
- コマ番号で絵が変わるエフェクト（`int(ctx.fi / 2) % 3` のように番号でコマを回す・番号を種にする）は 60fps で速さが変わります。次のいずれかで対処します：
  1. 時刻（`ctx.t`）で書き直す。
  2. そのままにするなら `META` に `'uses_fi': True` と注記する（マスター書き出しは止めずに「注意」として表示）。
  3. タイムラインの fps（`fps0 = getattr(ctx.eng, 'tl_fps', ctx.fps)`）のコマで数える（偽マリアの effects で使った形）：
     - `fi = ctx.fi if fps0 == ctx.fps else int(round(ctx.t * fps0))`
     - 「何コマ目か」は `int((t − 拍) * fps0)`
     - 通常の fps では今までと同じ値になり、60fps では 24fps 時と同じ模様が同じ長さだけ出ます（追跡・顔の点・自前で読むマスクのコマ番号もこれで合います）。

### 対応の手引き

1. `params` と本体の数値のうち px のもの（大きさ・太さ・ずれ・半径・余白・字の大きさ）に `* ctx.scale` を掛ける。
2. 面に散らばる数に `* ctx.scale ** 2` を掛ける。
3. 画像を貼る物は、貼る絵を `s` 倍の大きさで作る（拡大して貼らない。4K で細かく描くのが目的）。
4. `ctx.fi`・`ctx.sfi` を使っていないか確認する（使っていれば 5 で注記）。
5. `META` に `'scale_aware': True`（必要なら `'uses_fi': True`）を書く。
6. `scale 1` の静止画が直す前と SHA で一致することを確認する。
7. `mittler stills … --master-scale 2` の絵を半分に縮めて、`scale 1` の絵と位置・大きさが合うことを確認する（画素一致ではなく、4K のほうが細かくて正しい）。

### よく出る実装パターン（偽マリアの 21 本から）

- `params` の px は `if s != 1:` の中で `s` 倍にする（`scale 1` の計算に手を入れない）。
- 固定の px は `12.0 * s` のように掛ける（`s` が `int` の `1` なら値も型も同じ）。
- 「動かすか」の下限（`abs(dx) > 0.2`）も `0.2 * s` にする。
- 形を広げるカーネル（3×3）は `2 * s + 1` にする。
- 乱数で位置を決めるものは、乱数はタイムラインの大きさのまま引いて結果を `s` 倍にする（`scale 1` の絵を 2 倍にした位置になる）。
- 中の px を直せない部品（`mittler.lib.look` のキラ・ラメ）は、タイムラインの大きさで描いて `s` 倍に広げてもよい（位置は合う。細かさは FHD のまま）。
- 2 倍で描いて縮める字（字のシールの `SS`）は、4K キャンバスでは縮めずに 1 倍で描く（行の `x`・`y`・`size` を `s` 倍にして渡す＝いつもの内部 2 倍の絵と同じ細かさ）。

### 対応済み一覧と確かめ方

- 対応済み：`effects_lib/common/fade.py`（フェード）、`effects_lib/false_maria/` の 6 本、`effects_lib/beatfx/` の 9 本（2026-10-31、ビート演出）。作品の `effects/` は作ったときの写しなので、対応版を使うには作品へ写します。
- **確かめ方**：
  - 4K・60fps の静止画：`python -m mittler stills <tl> --at 5 --out <フォルダ> --master-scale 2 [--master-fps 60]`
  - 書き出し前チェックのみ：`python -m mittler master <tl> <出力> --check`

## 3D のエフェクト（2026-11-13、3D 強化）

3D の演出は 2 通りあります（入れ方・GPU の注意は `docs/インストールガイド.md` の 14）。

| エフェクト | すること |
|---|---|
| `gl_cards3d`（3D の板） | 絵・動画のコマ（ffmpeg でその時刻へ正確に飛ぶ）・`@frame`（このエフェクトより下の今の絵）を板にして、`ring`・`wall`・`fan`・`single` に並べて回す。角丸・映り込み・影 |
| `gl_particles3d`（奥行きのある粒子） | `fly`（手前へ流れる）・`drift`・`rise`。遠い粒は小さく暗く、ピントの外はぼける。足して明るくする |
| `gl_lightrays`（光の筋） | `warp`（ワープの筋）・`beams`（回る光の帯）・`rise`。足して明るくする |
| `blender3d`（Blender の 3D） | Blender で描いた場面を重ねる（タイムライン形式の「Blender の 3D のクリップ」） |

- いずれも `effects_lib/common/` にあります（新しい作品には自動配布しません）。編集画面の「エフェクト」タブ →「部品の置き場」→「作品に入れる」（または `POST /api/effects/add {name}`）で作品の `effects/` に写します。`blender3d` を入れると、場面のひな形 `templates/3d/*.py` も作品の `3d/` に写ります。

> **立体の文字は部品に入れていません**（決まった形の 3D 文字はチープに見えるため同梱せず、その場で作ります）。
> 要るときは、その作品の場面に合わせて作品の `effects/<名前>.py` をその場で書きます（下の `sc.text`・`text_layout`・`glyph` で字ごとに動かせます。Blender なら `mittler_bpy` の `text3d`・`letters`）。
> 決まった形の使い回しはせず、書体・厚み・面取り・質感（金属・ガラス・塗り）・光の当て方・映り込み・ぼけ・グレイン・動きの速さを、前後のカットと並べた静止画で見ながら場面になじむまで詰めます（3D はそのままでは極めてチープに見えやすい：`docs/スターターガイド（AI用）.md` の 7.7）。字の見た目に迷ったら、先に画像生成で画面まるごとのモックを作ってそれを再現します。

### GPU の 3D を書く（`pyengine/mittler/gl3d.py`）

```python
from mittler import gl3d

def apply(ctx, f, clip):
    lt = ctx.t - clip['start']                     # クリップの頭からの秒（絵はこれだけで決める）
    def build(sc):                                  # 物を置く（GL のスレッドで呼ばれる）
        sc.camera(gl3d.orbit((0, 0, 0), yaw=20 * lt, pitch=10, dist=6), (0, 0, 0), fov=35)
        sc.light(dir=(-0.5, 0.8, 0.9))
        sc.floor(y=-1, reflect=0.35, shadow=0.5, alpha=0.0)   # alpha 0：床は見えず、映り込みと影だけ下の絵に落ちる
        sc.text('Mittler', gl3d.find_font(None, ctx.root), depth=0.3, color=(1, .85, .5), metal=0.7)
        sc.card(img, gl3d.rot_y(30), w=1.6, h=0.9)              # img は uint8 の絵（gl3d.media_frame で作品の絵・動画のコマ）
        sc.points(P, 0.03, (1, .8, .5))                         # 光の粒（足す）。sc.streaks(P0, P1, 幅, 色) は光の筋
    rgba = gl3d.render(ctx.W, ctx.H, build, samples=gl3d.samples_for(ctx))  # H×W×4 の uint8（色は alpha を掛けたもの）。ドラフトは MSAA なし
    return gl3d.over(f, rgba)                       # 重ねる（光だけなら gl3d.lighten）
```

- **遅延 import**：`moderngl` は `gl3d` が使うときに初めて読み込みます。エフェクトの冒頭で `import moderngl` しないでください（3D を使わない作品が、`moderngl` の無い PC で開けなくなります）。
- **GL が無い PC**：`gl3d.render` が `GLUnavailable`（「3D の描画が使えない（理由）」）を投げて、その時刻の絵は描けずに止まります（黙って抜かしません）。かかっていない時刻は描けます。
- **基本ルール**：時刻とクリップの頭からの秒だけで決める（前のコマを覚えない）・乱数は `np.random.default_rng(決まった種)`・ドラフトは粒を減らす・MSAA を切る。大きさを画面の高さに対する割合で決めれば `ctx.scale`（マスター書き出しの 4K）にそのまま対応できます（`scale_aware`）。
- **用意されたヘルパ**：
  - 形の部品：`quad`・`box`・`text_layout`・`glyph`（字の輪郭から立体）
  - 行列：`translate`・`rot_x/y/z`・`scale`・`chain`・`look_at`・`perspective`・`orbit`
  - 曲線：`smooth`・`ease_out`・`back_out`
- **3D のある作品の例外**：GPU で描くため、別の PC・別の GPU・別のドライバーでは画素の値が少し違うことがあります。同じ PC・同じ設定なら同じ時刻は同じ絵になります（静止画・プレビュー・書き出し・並列数によらない）。`tools/smoke_3d.py --require-gl` で確認します。
- **スレッド構成**：GL の文脈はプロセスに 1 つで、`gl3d` 専用スレッドで作って描きます（描画サーバーがリクエストごとに別スレッドで描くため）。`build` はその専用スレッドで呼ばれます。

### 書き出しの前の下ごしらえ（`prepare`）

エフェクトに `prepare(eng, clip, n0, n1, step, check, progress)` があると、`mittler video`（マスター書き出しも含む）は区間に分けて描き始める前に、そのクリップへタイムラインのコマ `[n0, n1)`（`step` おき）を渡します（Blender の 3D がまとめて描くために使います）。

- `check()` は中止（`.cancel`）時に例外を投げます。
- `progress(できた数, 全部)` は `PHASE <名前> d n` の行になります。
- `prepare` の無い作品は何もしません（従来どおり）。

## HTML のレイヤー（エフェクト `html`、2026-11-18）

バニラの JavaScript や three.js で書いた絵を Python エンジンの Mittler でも重ねられる、HTML ベースの VFX レイヤーです。作品内の HTML ページ（Canvas 2D・CSS・SVG・WebGL・three.js）をヘッドレス Chromium（Playwright）でコマごとに描き、そのトラックの位置に重ねます（`pyengine/mittler/htmllayer.py`）。

### 入れ方とパラメータ

- 編集画面の「エフェクト」タブ →「部品の置き場」→ `html`（HTML のレイヤー）を「作品に入れる」と、作品の `html/` にひな形（`kinetic`＝文字の動き・`particles3d`＝three.js の光る粒・`shapes3d`＝three.js の立体の形）と `html/vendor/three.module.min.js`（three.js r170、MIT、`three.LICENSE`）が入ります。
- クリップの `params`：`page`（`html/<名前>/index.html`）・`args`（ページに渡す JSON）・`seed`（乱数の種）・`blend`（`over`・`add`・`screen`）・`opacity`。

### ページの書き方

下地 `pyengine/mittler/html_runtime.js` がページより先に読み込まれます。

```html
<script type="module">
import * as THREE from '../vendor/three.module.min.js';      // ライブラリは作品の html/vendor/ に置いて相対で読む（外の URL は読めない）
const M = window.mittler, W = M.W, H = M.H;                   // 描く大きさ（px。マスター書き出しでは 2 倍＝M.scale）
// ここで場面を組む（1 回だけ）。Math.random() は種で決まる
M.onFrame((t, args) => {                                      // t：クリップの頭からの秒。args：クリップの args
  // t だけで絵を決めて描く（renderer.render など）
});
</script>
```

- **`window.mittler` の中身**：`W`・`H`・`fps`・`scale`・`draft`（下書き。粒を減らすなど）・`seed`・`args`・`dur`（クリップの長さ 秒）・`t`・`onFrame(fn)`（`async` でも可）・`ready(promise)`（画像・書体を読み終わるまで待たせる）・`random()`。
- **絵は `t` だけで決める**：前のコマからの差分（`clock.getDelta()`・物理の積み上げ）で動かさないでください（並列書き出しは区間ごとに別ブラウザで途中のコマから描きます）。Mittler が `Date.now()`・`performance.now()`（いまの `t`）・`requestAnimationFrame`（1 コマに 1 回）・`Math.random()`（種＋コマ番号。ページ読み込み時は種だけ）を制御しているため通常の書き方でも時刻はそろいますが、積み上げの動きはずれます。`setTimeout`・`setInterval` で動かさないでください。
- **背景は透明のまま**：`body`・`canvas` に背景色を付けません（three.js は `alpha: true`、`setClearColor(0x000000, 0)`、`preserveDrawingBuffer: true`）。光るもの（足す光）は `blend` を `add` か `screen` にします。
- **読み込み範囲の制限**：ページから読めるのは作品の `html/` と `assets/` だけです（`127.0.0.1` の小さなサーバーが配信します。外への通信はできません）。画像は `../../assets/…`、書体は CSS の `@font-face` で読み込みます。
- **書体は最初のコマより前に読み込む**：ブラウザは書体を「初めて使われたとき」に読むため、そのままだと Canvas の文字は最初のコマだけ代わりの書体（システムの書体）で描かれ、次のコマから字体がカクッと変わります。並列の書き出しは区間ごとに新しいブラウザで描くので、区間の頭ごとに起きます。
  - 下地は、描いている間に書体の読み込みが始まったら、読み終わるのを待ってから同じ時刻を描き直します（2026-11-22〜。使った書体だけを読みます）。ふつうはこれで足ります。
  - 書体のファイルは大きい（日本語の書体は 1 本 10 MB を超えることもある）ので、ページの `@font-face` には使う書体だけを書きます。並列の書き出しでは、HTML のクリップごとに書体を読み直します。
  - 描き直しで間に合わない書き方（JavaScript の `FontFace` で足して、読み込みを待たずに使うもの・CSS を後から差し込むもの）は、`window.mittler` の `ready(…)` に `document.fonts.load('700 64px "書体の名前"', '使う字')` を渡して、読み込んでから描きます。
  - 確かめ：区間の頭になりうるコマ（クリップの頭・カットの頭）を静止画で描いて、最初のコマから目的の書体になっているかを見ます。
- **歌詞の書体は、意図が無ければ途中で切り替えない**：区間ごとに明朝とゴシックが入れ替わると、ちぐはぐに見えやすいです。字間の伸縮・斜体の傾き・弾む拡大などの出し方も、多く重ねると歌詞が読みにくくなります。迷ったら、書体を 1 つにそろえ、出し方は控えめ（フェードと小さな動き）から始めて、見せ場だけ強くします。
- **エラー時**：JavaScript のエラーがあると、その時刻を描かずに理由つきで止まります（「HTML レイヤー：ページの JavaScript でエラーが発生しました」）。

### 速さ・キャッシュ・使い分け

- **速さとキャッシュ**：FHD で 1 コマ 0.1〜0.3 秒（作者の PC。ブラウザ起動は初回 1 秒ほど）。書き出し時は区間ごとにブラウザを 1 つ使います。ためた絵（`fcache`）の鍵には、ページのフォルダの中身と `html/vendor/`、下地が入ります（ページを直すとそのページのコマだけ描き直します）。
- **GPU の差**：GPU で描くページ（WebGL）は、3D と同じく別の PC・GPU で画素が少し違って構いません。同じ PC なら同じ時刻は同じ絵になります（`tools/smoke_html.py`）。
- **選び方**：文字の動き・UI 風モーショングラフィック・図形・パーティクル・three.js の 3D は HTML のレイヤーが速く書けます（AI の得意な書き方）。動画の絵そのものを加工する（色・マスク・歪み）のは Python のエフェクト（`ctx` と numpy）が向きます。**3D はそのままでは極めてチープに見えやすいので、場面になじむまで詰めます**（AI 用ガイドの 7.7）。

## window（クリップの長さとパラメータの対応）

クリップをドラッグで動かす・端で伸ばすときに、編集画面がパラメータもいっしょに直すための約束です。

| 書き方 | 意味 |
|---|---|
| `{'start': 't', 'dur': 'dur'}` | クリップの頭＝`params.t`、長さ＝`params.dur` |
| `{'start': 't0', 'end': 't1'}` | 頭＝`t0`、終わり＝`t1` |
| `{'start': 't_in', 'lead': 0.05, 'end': 't_out'}` | 頭＋0.05＝`t_in`（少し早く始まる物） |
| `'extra': 'life'` | 長さ＝`dur`＋`params.life`（スプレーの粒の寿命） |
| `{'move_only': True}` | 動かせるが長さは変えない（ワイプ・外周ネオン） |
| `{'per_cut': True}` | カットの長さに合わせる（カットごとの設定。動かさない） |
| `{'fixed': True}` | 動かさない |

## 足したエフェクトを使う

1. `effects/<名前>.py` を書きます。
2. タイムライン（`*.cut.json`）に、処理したい順の位置へトラックとクリップを追加します：
   ```
   {"id": "t_<名前>_0", "name": "…", "kind": "effect", "effect": "<名前>", "clips": [{"id": "<一意>", "type": "effect", "effect": "<名前>", "start": 秒, "dur": 秒, "params": {…}}]}
   ```
   （`tracks` の先頭がいちばん手前。人のマスクを使うなら「人のマスク」より手前、字の下にかけたいなら「字のシール」より奥に置きます。）
3. 編集画面は保存を検知して描き直します（描画サーバーがタイムラインと `effects` を読み直します）。
