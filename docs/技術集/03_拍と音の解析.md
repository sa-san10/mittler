# 03 拍・オンセット・打点（曲の解析）

**何のため**：カットを拍で切る、揺れ・光・寄りを打点に合わせる、音ハメの目標にする、歌詞の出だしの手がかりにする、静かな箇所（揺らさない箇所）を把握する、といった用途に使います。
Mittler では、拍をタイムラインのメタデータ `beats`（`[[秒, 小節の頭か, 強さ], …]`）として持ち、エフェクトから `ctx.beats` で読み込みます。

## 1. 拍：librosa の beat_track
- **使った作品**：Attention・False Maria。
- **しくみ**：`librosa.beat.beat_track(y, sr=22050, units="time")` で拍を抽出します。あわせて `onset_strength`・RMS・1 秒ごとの音量・静かな箇所（RMS が最大の 6% 未満の状態が 0.15 秒以上続く区間）も算出します。
- **位相のずれに注意**：`beat_track` の拍は、実際の打音から数十ミリ秒ずれます。新しい曲では必ず測り直し（打点の山と拍の差の中央値）、ずらした後の値を Mittler に入れます。
  - **Attention**：拍が打音より**約 40ms 遅れていた**（スペクトルフラックスで計測し中央値 −40〜−43ms）ため、拍を −0.040 秒ずらして使いました。
  - **偽マリア**：逆に拍が**約 45〜56ms 早かった**ため、＋0.045 秒ずらしました。
- **小節の頭**：拍の番号の mod 4 で判定します（曲ごとに確認が必要です。偽マリアは mod 4 が 0、Attention は 3 が頭でした）。
- **要るもの**：librosa。

## 2. 打点（オンセット）・キック・機械ノイズ：numpy だけ
- **使った作品**：偽マリア（numpy と ffmpeg のみで実装）。
- **しくみ**：
  1. STFT（2048／256）から、オンセット（スペクトルの増え方）・RMS・低域（キック）・高域（ノイズ）・スペクトルの平らさ（機械ノイズは平ら）を計算します。
  2. 打点の山（適応しきい値、強さ 0〜1、ノイズ・キックの値つき）、拍のずれと拍ごとの強さ、0.1 秒ごとの音量を出力します。
  3. オンセットの時刻は、元の波形の 5ms 単位のエネルギーで精密化します。
- **演出の割り当て**：
  - カットごとに「気分・ショット・理由・効果」の表を作り、人が読める演出表としても出力します（止めたいカットは `off`）。
  - 強い打点（小節の頭、またはキックの強さ 0.6 以上）に、寄り・色ずれ・白い光・リム・アナモルフィック・放射ブラー・ダッチを当てます（10 の「画面の演出の語彙」）。
- **作者の決まり**：振動やフラッシュは要所のみに留めます。画面の振動は大きくしすぎず、小さく細かく刻みます。

## 3. ステムに分けて調べる：demucs ＋ フラックス
- **使った作品**：Attention（歌詞の出だし・ドラムの打音・伴奏が抜ける瞬間）、偽マリア（曲のステムが別途あった）。
- **しくみ**：
  - demucs の `htdemucs` で `vocals`／`drums`／`bass`／`other` に分離します（CPU でも動作し、対象区間だけ切り出すと高速です）。
  - ステムごとに 0.1 秒単位の RMS（dB）を並べて「どこで何が鳴っているか」を可視化し、`librosa` の `onset_detect` でドラム・ボーカルの打点を取ります。
  - **歌の出だし**：ボーカルのステムに対し、帯域ごと（全体 80〜11000Hz・子音 3500〜11000Hz・母音 150〜2500Hz）の対数スペクトルフラックスの山と RMS の推移を見ます。
  - **曲の終わり・抜き**：音が −60dB を切る箇所や、伴奏が抜ける瞬間を検出します（短い版の終わりを決めるのに使いました）。
- **要るもの**：demucs・torch・soundfile・librosa。

## 4. 別の AI に聞く（構成・雰囲気）
- 曲を音の分かる AI（作者は Gemini を使用）に聞かせて、構成（イントロ・A メロ・サビなど）と雰囲気を出させます。
- 時刻は粗いため、正確な時刻は聞き取り（04）と拍を正とします。手順の詳細は 12 を参照してください。

## Mittler で使うには
- **拍**：解析の `beats`（librosa。`[[秒, 小節の頭か]]` とテンポ）を使います。音楽クリップを右クリック →「解析」、または `python .mittler/api.py . analyze <クリップ> beats` で実行します。
  - 位相のずれ（上の 1）は、打点と比べて補正してからメタデータに入れます。
- **ステム**：解析の `stems`（ボーカルと伴奏）を使います。Suno の曲は Suno 側からステムを取得できます。
- **細かい打点解析**：キック・ノイズの値つき打点解析は Mittler にありません。必要な場合は上の 2 のしくみを作品の道具として実装し、結果を素材に配置します。打点はエフェクトの時刻パラメータを合わせる先にも使えます。
