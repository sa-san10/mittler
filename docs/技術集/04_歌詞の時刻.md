# 04 歌詞の単語・文字の時刻

**何のため**：歌詞の文字を歌に合わせて表示する（1 語ずつ・1 文字ずつ）、カットや演出のきっかけにする、といった用途に使います。
Mittler では、歌詞の時刻をタイムラインのメタデータ `lyrics`（`{start, end, text}`）、またはエフェクトの `params` に持ちます。

## 1. faster-whisper の単語の時刻（聞き取り）
- **使った作品**：False Maria・偽マリア・Attention・紙芝居（セリフの区切り：09）。
- **しくみ**：`WhisperModel(<small|medium|large-v3>)` で次のように実行します。
  ```python
  transcribe(wav, language=…, word_timestamps=True, vad_filter=False, condition_on_previous_text=False)
  ```
- **精度を上げるコツ**：
  - **歌詞を `initial_prompt` に入れる**と、歌詞どおりの単語が出やすくなります（プロンプトあり・なしの両方を出して見比べると効果的です）。
  - **ボーカルだけ（demucs で分けた `vocals`）に聞かせる**と、伴奏に引っ張られません。区間だけ切り出して処理した場合は、切り出し開始の秒を結果に足します。
- **弱いところ**：
  - 歌の頭が早く／遅く出ることがあります（Attention では、ある語の頭が whisper より約 0.25 秒早く、whisper は語の途中の強い音に合わせていました）。
  - 歌詞にない繰り返し（同じ語が 4 回続く箇所など）を落とすことがあります。
- **要るもの**：faster-whisper。小さいモデルは CPU で足りますが、`large-v3` は GPU があると高速です。

## 2. 強制アラインメント（正式な歌詞を音に合わせる）
- **使った作品**：偽マリア。「正式な歌詞を唯一の正本にする」という方針で設計しました。
- **しくみ**：
  1. **入力の準備**：音はボーカルのステムを使います。歌詞は正式な文字のみとし、**読み（ひらがな）は手で書きます**（英語は実際に歌っている音で書きます）。`(正式な文字の一部, 読み)` の並びを作り、結合すると正式な行に戻ることを検証します。
  2. **アラインメント**：torchaudio の **MMS_FA**（wav2vec2 の CTC、多言語・ローマ字）を、区間ごとの音に対して、その区間の全行の読みでかけます。行のあいだには「`*`」（歌詞にない音を吸う記号）を入れます。読みの単位ごとの始まり・終わりを求め、文字単位に割ります。
  3. **照合**：`faster-whisper large-v3` の行頭およびボーカルのオンセット（librosa）と比較し、ずれが大きい行に印を付けます。
  4. **行の終わりの決定**：最後の単位の終わりの後、ボーカルの音量が下がる箇所（伸ばしを含む）を行の終わりとします。
  5. **出力**：手で修正できる JSON（行・単位・文字ごとの始まり／終わり）と、照合レポートを出力します。
- **要るもの**：torch・torchaudio・faster-whisper・librosa。

## 3. 音で出だしを詰める（オンセットに合わせる）
- **使った作品**：Attention。
- **しくみ**：ボーカルのステムから次の指標を出し、whisper の単語をこれに合わせます。判断に迷った箇所は根拠をファイルに残します。
  - メルスペクトログラムのフラックス（静かな箇所は無視）の山
  - RMS のくぼみ（音節の切れ目）
  - −38dB を上に越える箇所（声の出だし）
  - 伴奏の打点（クラップ）
- **結果の形**：フレーズ／行／単語／始まり／終わり／スタイル／高さの表を作成し、スケジュール JSON に変換します（単語の先頭の `+` は、前の語に空白なしでつなぐ印）。

## Mittler で使うには
- **聞き取り**：解析の `transcribe`（faster-whisper large-v3、単語の時刻つき）を使います。ボーカルだけにする場合は先に `stems` を実行します。
  - コマンド：`python .mittler/api.py . analyze <クリップ> transcribe`
- **修正**：歌詞のメタデータは右の「メタデータ」タブで修正できます。Suno の曲を採用すると、歌詞が自動でメタデータに入ります。
- **1 文字単位の精密な同期**：強制アラインメントとオンセットに合わせる道具は Mittler にありません。1 文字ずつ正確に出したい場合は、上の 2・3 のしくみを作品の道具として実装し、結果をメタデータかエフェクトの `params` に入れます。
