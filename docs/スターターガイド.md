# Mittler スターターガイド

Mittler は、VS Code の中で動く **Windows 専用**の動画エディタです。タイムライン（`*.cut.json`）に動画・画像・字幕・セリフ・音・エフェクトを並べ、止めた場所の 1 コマを本番と同じ絵で確かめながら MP4 に書き出せます。

横で AI のエージェント（Claude Code など）に頼むと、エージェントが同じファイルを編集し、結果がすぐ画面に反映されます。このページは最初の短い入口です。詳しい説明は、各章の終わりにある関連文書を参照してください。

## 1. インストール

必要な環境は次のとおりです。**Node.js は不要**です（VS Code に内蔵された Node で動きます）。

- **VS Code**
- **Python 3.12 以上**
- **ffmpeg**（full build）
- **Git**

### 配布版（通常はこちら）

1. Mittler の VSIX（`mittler-<版>.vsix`）を GitHub の Releases などから入手します。
2. VS Code の「拡張機能」→ 右上の「…」→「**VSIX からのインストール…**」から VSIX を選びます（コマンドなら `code --install-extension mittler-<版>.vsix`）。
   - 導入後（および次の VS Code 起動時）に、右下に通知が 1 度だけ表示されます。描く python や ffmpeg が足りないときは「Mittler を使う準備：… が見つからない」と「Mittler: 初期設定」ボタンが、そろっていれば「新しい作品を作る」ボタンが出ます。
3. 通知のボタン、またはコマンドパレット（Ctrl+Shift+P）から「**Mittler: 初期設定**」を実行します。
   - 必要なものがそろっているか確認し、結果を「出力」パネルの「Mittler」に表示します。
   - 描画用の Python パッケージが無い場合は、「描く python を入れる…」を押すと内容を確認してからインストールされ、設定も自動で書き込まれます。
   - ffmpeg・Python・Git が無い場合は、導入方法（winget のコマンド）が表示されます。
4. 更新するときは、新しい VSIX を同じ手順でインストールするだけです。

### 開発版（Mittler を直す人向け）

リポジトリを clone し、それを読み込む入口をインストールします。

```
git clone https://github.com/sa-san10/mittler.git mittler
cd mittler
python setup\mittler_setup.py
```

`mittler_setup.py` は必要なものがそろっているかを確かめ、足りないものと入れ方を 1 画面で表示します（この時点では何も変更しません）。足りないものの導入まで任せる場合は、次を実行します。

```
python setup\mittler_setup.py --install-venv <venv を作るフォルダ> --install-extension
```

- `--install-venv <フォルダ>`：描画用の Python 環境を指定フォルダに作成します（numpy・opencv・Pillow を取得します。場所はどこでも構いません）。
- 先に `--dry-run` を付けると、何を実行するかだけを確認できます。
- `--install-extension`：VS Code に Mittler の拡張をインストールします（`python tools\install_vscode.py` と同じです）。

最後に出力される「VS Code の設定に書く」の行（`"mittler.render.python": "…"` など）を VS Code の `settings.json` に追記し、VS Code で「ウィンドウの再読み込み」を行います。その後もう一度 `python setup\mittler_setup.py` を実行し、足りないものが無ければ完了です。

> 詳しくは [インストールガイド](インストールガイド.md)（配布版と開発版の入れかえ・設定の一覧・ほかの PC で描く・セリフの鍵・解析・マスター書き出しの道具・安全）をご覧ください。VSIX の作り方は [配布](配布.md) にまとめています。

### 画面の言葉

初期状態は英語です。日本語にするには、編集画面の上のバーの右端にある **EN／日本語** から「日本語」を押します。

- その場で切りかわり、次回からも日本語で開きます（VS Code 内では設定 `"mittler.language": "ja"` に保存されます）。
- 先に `settings.json` へ `"mittler.language": "ja"` と書いておいても構いません。
- 言語設定は PC ごとの設定であり、作品ファイルには書き込まれません。

## 2. エージェントに初期設定を任せる

配布版であれば、1 のコマンド「Mittler: 初期設定」だけで十分です。開発版で 1 の手順を自分でやる代わりに、VS Code で Mittler のフォルダ（clone した場所）を開いてエージェントに次のように伝えてください。

> **Mittler の初期設定をして**

エージェントはリポジトリの根にある [`AGENTS.md`](../AGENTS.md) を読み込み、`setup\mittler_setup.py` で環境を確認して不足分を報告します。パッケージの導入や設定の書き込みは、必ず内容を伝えて許可を得てから進めます（黙って実行しません）。完了後は再度確認して結果を伝えます。

- `AGENTS.md`：エージェントが最初に読む入口です（どこに何があるか・初期設定・作品を直すときの決まり）。Claude Code は根の `CLAUDE.md` からこれを読み込みます。
- 作品ごとの説明と決まり（作品の `AGENTS.md`。Claude Code は作品の `CLAUDE.md` から読み込む）や、話しかけるたびに編集画面の今をエージェントに添えるフック（作品の `.claude/settings.json`）は、作品を作ると自動で入ります。
  - 作品のファイルには Mittler の場所を書きません。その PC 用の情報（Mittler の場所・AI 用ガイドの写し）は、編集画面が作品を開くたびに作品の `.mittler/` に書き出されます。
- Claude Code のスキル（空のフォルダで「Mittler で新しいプロジェクトを始めたい」と言うと作品を作る）は、`python setup\mittler_setup.py --install-skill` で入れられます。

## 3. 新しい作品（プロジェクト）を作る

作品は 1 つのフォルダ（タイムライン・エフェクト・素材）として管理し、ひな形から作成します。次のどの方法でも同じものができます。

| やり方 | 手順 |
|---|---|
| **「＋ 新規」ボタン** | 編集画面の上のバーの **＋ 新規** → 置く場所・フォルダの名前・表示名・大きさ・fps・長さ → **作る** |
| VS Code のコマンド | Ctrl+Shift+P →「**Mittler: 新しい作品を作る**」（まだ作品を 1 つも開いていないときはこちら） |
| エージェントに頼む | 空のフォルダを VS Code で開いて「**Mittler で新しいプロジェクトを始めたい**」（「縦のショートで」「90 秒」なども添えられます） |
| コマンドライン | `tools\mittler.cmd node tools\new_project.js <作品フォルダ> --title "表示名" --width 1920 --height 1080 --fps 30 --duration 60 --lang ja` |

作成時のルールと生成物は次のとおりです。

- **作品のフォルダは、Google ドライブ・OneDrive・Dropbox などの同期やバックアップの対象にしないでください**。Mittler は描いたコマを作品の `work/cache/frames/` に何千枚もためる（上限は既定 40 GB）ので、同期のアプリがそれを全部写して送り、ディスクと通信が重くなります。作品の受け渡しは git か、書き出した MP4 で行います。どうしても作品のフォルダを同期したいときは、VS Code の設定 `mittler.cache.dir` にためた絵の置き場（同期しないフォルダ）を書くと、ためた絵が作品の外に置かれます（インストールガイドの 12）。
- フォルダの名前は**英数字と `-` `_` だけ**にしてください。中身のあるフォルダには作れません。幅と高さは偶数にします。
- 最初のトラック・メタデータの段の名前（字幕・映像・カット…）は、作るときの言語になります。「＋ 新規」は画面の言葉、コマンドは設定 `mittler.language`、コマンドラインは `--lang`（既定は英語）が使われます。名前はあとから変えても構いません。
- 作成されるもの：`<名前>.cut.json`（タイムライン）・`effects/`（字幕・重ね絵・フェード・色）・`assets/`（素材を入れる）・`output/`（書き出し）・`AGENTS.md`・`CLAUDE.md`・git の最初のコミット。

> 詳しくは [人間用ガイド](スターターガイド（人間用）.md) の 2 をご覧ください。エージェント向けの手順は [新しい作品を始める（AI用）](新しい作品を始める（AI用）.md)、ひな形は `templates/` にあります。

## 4. 作業を始める・便利な機能

1. VS Code で**作品のフォルダ**を開き、`<名前>.cut.json` をクリックして編集画面を開きます。右側にエージェント（Claude Code など）を開いておきます。
2. 素材（画像・動画・音）をエクスプローラーで `assets/` の下に入れます。左のアセット窓に表示されるので、選んで「置く」を押します。
3. タイムラインでクリップを動かす・伸ばす・切るなどの編集をします。**保存は自動**で、間違えたら Ctrl+Z で戻せます。
4. 再生を止めると、その時刻の**本番と同じ 1 コマ**が表示されます（Space で再生／停止、← → で 1 コマ移動）。

### 便利な機能

| 機能 | 使い方 |
|---|---|
| エージェントに頼む | クリップを選ぶか時刻を止めて、「これの字幕を短くして」「ここに画面が揺れるエフェクトを足して」と伝えます。選んでいるもの・時刻・映っている 1 コマは自動でエージェントに伝わります |
| 書き込み | 止めた画面にペン・矢印・丸を描いて「AI に渡す」を押すと、その絵を指して頼めます（Claude Code なら次の話しかけに自動で添えられ、ほかの AI にはクリップボードにコピーされた文を貼ります） |
| カット編集 | タイムラインの上の道具のバーから操作できます：選択（V）・カット（C）・スリップ（Y）・再生位置で分割（Ctrl+K）・リップル削除（Shift+Delete）・コピー／貼り付け |
| スナップ | クリップの端・再生位置・カットの境目・拍に吸いつきます（S キーで切りかえ） |
| セリフ（TTS） | 「キャラ」タブでキャラを作り、TTS のトラックで文を書いて「生成」（Gemini TTS／VOICEVOX）を押します。「セリフから字幕を作る」も使えます |
| エフェクト | アセット窓の「エフェクト」タブから置きます。新しいものはエージェントに「〇〇なエフェクトを作って」と頼めます（中身は `effects/*.py`） |
| 3D | 「エフェクト」タブの「部品の置き場」から 3D の板・奥行きのある粒子・光の筋（GPU）や Blender の 3D を「作品に入れる」→ 置きます。GPU（moderngl）や Blender が必要です（[インストールガイド](インストールガイド.md) の 14） |
| PNG | 表示中のコマを劣化なしの PNG で保存します（`output/stills/`） |
| 長さ・大きさ | 上のバーの時計のアイコンと、今の大きさのボタンから動画の長さ・大きさを変更できます |
| 読み直す | 画面がおかしいときや、外で作った絵が出ないときに画面を読み直します |

ボタンやトラックの印は 1 色の線のアイコンです。画面幅が狭いとアイコンだけになりますが、マウスを乗せると名前が表示されます。

> 詳しくは [人間用ガイド](スターターガイド（人間用）.md)（画面・操作の一覧・動画化予定・解析・音ハメ・困ったとき）をご覧ください。エージェント向けは [AI 用ガイド](スターターガイド（AI用）.md)、[タイムライン形式](タイムライン形式.md)、[エフェクトの書き方](エフェクトの書き方.md) を参照してください。

## 5. 完成動画を書き出す

1. 上のバーの **書き出し** を押します。
2. **品質**（最終／下書き／下書き（速い））、**範囲**（全体／一部）、**ファイル名**を選びます。
3. **書き出す** を押すと、作品の `output/<ファイル名>.mp4` に出力されます（途中で止められます）。完了後は「フォルダで表示」で開けます。

- **下書き**：コマを間引いて速く書き出します（確認・共有用）。納品には「最終」を使います。
- **マスター**：60fps の最終版です。「標準」は大きさそのまま、「高画質」は 4K で描いてから縮めます（高画質には Real-ESRGAN・RIFE が必要です。インストールガイドの 12）。
- **画面を使わずに書き出す場合**：描く python で、`pyengine` のフォルダから次を実行します。
  ```
  python -X utf8 -m mittler video <作品>\<名前>.cut.json <出力.mp4>
  ```

> 詳しくは [人間用ガイド](スターターガイド（人間用）.md) の 5「書き出し」「マスター書き出し」をご覧ください。

## 安全について

作品を開くと、その作品の `effects/*.py`（Python のコード）が実行されます。**知らない人の作品は、中身を確認してから開いてください。**

VS Code で信頼していないフォルダ（制限モード）では、Mittler は動作しません。詳しくは [インストールガイド](インストールガイド.md) の 11 を参照してください。
